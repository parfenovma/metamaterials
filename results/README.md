# Результаты

В Git хранятся только краткие отчёты, из которых понятны постановка,
нормировка, проверки и пределы вывода. Сетки, поля, сигналы, таблицы и рисунки
генерируются локально и игнорируются.

Текущая доказательная база относится только к изолированной извилистой
фотополимерной полосе:

1. [`staggered_waveguide_port_audit/README.md`](staggered_waveguide_port_audit/README.md)
   — энергетический и модальный аудит старого результата на `140 кГц`;
2. [`stg_modal_completion/README.md`](stg_modal_completion/README.md)
   — число периодов, дисперсия, короткие импульсы и скейлограммы;
3. [`stg_modal_completion/REPRODUCE.md`](stg_modal_completion/REPRODUCE.md)
   — команды воспроизведения.

Эти отчёты не доказывают повышение разрешения дефектоскопа. Следующий набор
результатов должен содержать прямое попарное сравнение двух близких дефектов в
алюминии для прямой и извилистой прослойки.
