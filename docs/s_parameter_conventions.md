# Соглашения для портов и S-параметров

Этот документ фиксирует соглашения до реализации модального анализа. Любое
изменение соглашений должно сопровождаться изменением версии формата данных.

## 1. Временная и частотная конвенция

Используется преобразование Фурье

```math
U(\omega) = \int u(t)\exp(-i\omega t)\,dt,
```

с обратным представлением физического поля как

```math
u(t) = \operatorname{Re}\{U(\omega)\exp(i\omega t)\}.
```

Для задержанного сигнала фаза передаточной функции убывает с частотой, поэтому

```math
\tau_g = -\frac{d\,\operatorname{unwrap}(\arg H)}{d\omega}.
```

## 2. Геометрия двухпортового блока

- Левый порт имеет внешнюю нормаль `n_L = (-1, 0)`.
- Правый порт имеет внешнюю нормаль `n_R = (1, 0)`.
- Общая касательная портов направлена как `t = (0, 1)`.
- Референсные плоскости располагаются в прямых однородных участках волновода.
- Соединяемые блоки обязаны иметь одинаковое поперечное сечение и одинаковый
  модальный базис на общей референсной плоскости.
- Портовая собственная задача использует пространственную зависимость
  `u(y) exp(gamma*x) exp(i*omega*t)`. Для распространяющейся вправо моды
  `gamma = -i*k`, `k > 0`.

## 3. Направления волн

Для каждого порта `a` обозначает волну, входящую в блок, а `b` - волну,
выходящую из блока:

```math
\begin{bmatrix}b_L\\b_R\end{bmatrix}
=
\begin{bmatrix}S_{LL}&S_{LR}\\S_{RL}&S_{RR}\end{bmatrix}
\begin{bmatrix}a_L\\a_R\end{bmatrix}.
```

Таким образом:

- `S_LL` - отражение при возбуждении слева;
- `S_RL` - прохождение слева направо;
- `S_LR` - прохождение справа налево;
- `S_RR` - отражение при возбуждении справа.

Каждый блок `S_pq` является матрицей по модам, а не одним числом, если на
порту учитывается больше одной моды.

## 4. Нормировка мод

Распространяющиеся моды должны нормироваться на единичный усреднённый поток
мощности через порт. Тогда квадрат модуля коэффициента непосредственно даёт
долю мощности только для ортогональных распространяющихся мод.

Эванесцентные моды не переносят среднюю мощность и требуют отдельного
соглашения о нормировке. Они сохраняются для описания ближнего взаимодействия,
но не суммируются напрямую в коэффициент энергетического пропускания.

В текущей реализации мощность моды через сечение с нормалью `+x` определяется
как

```math
P_x=-\frac12\operatorname{Re}\int
  (\boldsymbol\sigma\mathbf e_x)\cdot\mathbf v^*\,dy,
\qquad \mathbf v=i\omega\mathbf u.
```

Правонаправленная распространяющаяся мода нормируется на `P_x = +1 Вт/м`,
левонаправленная — на `P_x = -1 Вт/м`. Кинематические P/S-доли по дивергенции
и ротору используются только для классификации смешанных guided-мод и не
являются отдельными энергетическими каналами.

## 5. Минимальные проверки каждой S-матрицы

Для линейного пассивного взаимного блока проверяются:

1. сходимость по сетке, временному шагу и числу портовых мод;
2. взаимность после учёта выбранной нормировки;
3. пассивность: выходная мощность не превышает входную;
4. энергетический баланс с учётом демпфирования;
5. независимость результата от сдвига референсных плоскостей после внесения
   соответствующего фазового множителя;
6. совпадение композиции двух блоков с полным FEM-расчётом этой пары.

## 6. Формат данных v2

Текущий временной solver сохраняет предварительные портовые наблюдаемые:

- нормальное и касательное среднее смещение;
- нормальную и касательную скорость, полученную временным
  дифференцированием;
- нормальную и касательную среднюю компоненту вектора напряжений;
- ориентацию нормалей и касательной;
- тип и параметры профиля;
- параметры материала и расчёта.

Эти усреднённые величины предназначены для отладки одномодового приближения.
Они не являются полной модальной S-матрицей. Следующая версия формата должна
содержать коэффициенты проекции распределённых полей на моды портов.

## 7. Предварительная частотная постобработка

`step3_analyzer.jl` вычисляет отношение комплексных спектров только там, где
амплитуда входного спектра превышает заданный порог. Для образца и
прямоугольного референса одинаковой длины дополнительно вычисляется

```math
H_{cal}(f) = \frac{H_{sample}(f)}{H_{reference}(f)}.
```

Из него извлекаются относительная амплитуда, `|H_cal|^2`, фаза и добавочная
групповая задержка. До нормировки портовых мод по мощности `|H_cal|^2`
является только квадратом амплитудного отношения, а не энергетическим
коэффициентом. Такая калибровка удаляет общий спектр источника и общий
фазовый набег прямого волновода, но не разделяет падающую и отражённую моды.
Поэтому `H_cal` нельзя обозначать как элемент полной S-матрицы.

Для полностью записанного импульсного отклика по умолчанию используется
прямоугольное окно: одинаковое окно Ханна по-разному взвешивает разделённые во
времени входной и выходной импульсы и смещает оценку амплитуды. Сглаживающее
окно допускается после явного выбора временных gates либо для стационарных
сигналов. Если отклик не успел затухнуть к концу записи, следует увеличить
время FEM-расчёта, а не скрывать обрыв окном.

## 8. Соглашения для вейвлетной диагностики

Используется комплексное непрерывное вейвлет-преобразование Морле. Частотная
ось CWT должна храниться в герцах и соответствовать псевдочастотам выбранного
вейвлета при фактическом временном шаге каждого FEM-сигнала. Параметры вейвлета,
частотная сетка и нормировка являются частью сериализуемой конфигурации анализа.

Для стандартной записи длительностью `120 мкс` используется автоматическая
сетка с шагом `5 кГц`. Нижняя граница выбирается из требования, чтобы вне cone
of influence оставалось не менее половины временной записи,

```math
f_{min} = \frac{c_{COI}\,\omega_0}{\pi T(1-q)}, \qquad q=0.5,
```

и округляется вверх до шага сетки. При `omega_0=6` и
`c_COI=sqrt(2)` получается `f_min ≈ 45 кГц`, поэтому фактическая граница равна
`50 кГц`. Верхняя граница равна меньшему из `1 МГц` и `0.9 f_Nyquist`; для
текущих сигналов она составляет `1 МГц`.

Вейвлетные величины образца всегда сравниваются с прямоугольным референсом той
же длины, рассчитанным при той же несущей и временном шаге. Выходной сигнал сам
по себе допускается использовать для скейлограммы, но не для калиброванной
задержки или локального отношения прохождения.

Добавочная вейвлетная задержка определяется относительно референса. Она не
обозначается как `tau_g`: групповая задержка остаётся производной фазы
стационарной комплексной характеристики,

```math
tau_g(f) = -d\arg H(f)/d\omega.
```

Все оценки CWT обязаны хранить маску доверия. Из анализа исключаются:

- точки внутри cone of influence;
- области с недостаточной энергией входа или референса;
- локальное отношение `W_sample/W_reference`, когда знаменатель ниже порога;
- задержки, полученные из нескольких несопоставимых ridge без явного правила
  выбора.

Вейвлетная мощность `|W(f,t)|^2` является time-frequency мерой амплитуды. До
модовой нормировки портов она, как и `|H_cal|^2`, не называется коэффициентом
энергетического прохождения.

## 9. Правая граница переходного расчёта

Стандартный режим `right_boundary_condition=:absorbing` добавляет на правом
порту импедансную тягу для нормальной и касательной компонент скорости. Это
поглощающая граница первого порядка: она продолжает выходящий канал и уменьшает
искусственное отражение от конца конечной модели, но не является точным
многомодовым DtN-оператором.

Контрольный режим `right_boundary_condition=:free_reflecting` удаляет
поглощающий член. На правом торце тогда выполняется естественное условие
нулевой тяги, то есть получается свободная отражающая граница. Поскольку
нормальное напряжение на идеальном свободном торце равно нулю, сравнение
поглощающего и отражающего случаев выполняется по средней нормальной скорости
правого порта, а не по `right_normal_traction_mpa`.

График, построенный из переходных данных относительно прямоугольного референса,
обозначается `|H_cal|` и называется калиброванным амплитудным прохождением. Даже
при поглощающей правой границе это ещё не нормированный по мощности `S21`.
