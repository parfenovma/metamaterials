# Общий benchmark топологий для ультразвуковой дефектоскопии

> Этот benchmark начинается на уровне `L5 — physical geometry`. До запуска
> новых топологий архитектурный класс должен пройти gates `O0--O3` из
> [`measurement_operator_design_space.md`](measurement_operator_design_space.md).
> Существующие топологии разрешено использовать как калиброванные точки
> операторного пространства без нового geometric sweep.

Этот документ фиксирует общий виртуальный стенд и контракт результатов для
параллельного исследования изготовимых пассивных линз. Топология может менять
только область устройства перед образцом. Материал образца, возбуждение,
дефекты, референсы и метрики должны оставаться одинаковыми.

Цель сравнения — не максимальная гармоническая амплитуда сама по себе, а
обнаружимость дефекта при сохранении мощности и короткого импульса.

## 1. Общий виртуальный стенд

Первая ступень является 2D plane-strain surrogate; она не выдаётся за
осесимметричный или полный 3D-результат.

| Параметр | Значение |
|---|---:|
| Материал образца | Al 6061 surrogate |
| Плотность | `2700 kg/m^3` |
| Скорость P-волны | `6122.1024 m/s` |
| Скорость S-волны | `3083.8103 m/s` |
| Несущая | `242 kHz` |
| Импульс | `5-cycle Hann` |
| Полоса `-6 dB` | `193.8--290.1 kHz` |
| Полоса `-20 dB` | `162.2--321.7 kHz` |
| Высота/диаметр апертуры | `71.6 mm` |
| Максимальная осевая длина устройства | `55 mm` |
| Длина образца после интерфейса | `125 mm` |
| Высота 2D-образца | `71.6 mm` |
| Номинальная глубина фокуса | `60 mm` от интерфейса |

При пятицикловом импульсе длительность возбуждения равна примерно `20.66 us`,
а round-trip до глубины `60 mm` — примерно `19.60 us`. Поэтому эта постановка
намеренно чувствительна к звону и мёртвой зоне. Красивый фокус с длинным
ringing не должен выиграть benchmark.

Общий код конфигурации находится в
`src/code/metamaterial/ndt_benchmark.jl`; отдельные сетки образца строятся
`src/code/metamaterial/run_virtual_ndt_stand.jl`.

## 2. Обязательные референсы

Каждая топология считается вместе с двумя контролями.

1. `bare`: однородный алюминиевый образец без устройства при той же полной
   падающей энергии.
2. `straight_footprint`: нефокусирующее устройство с теми же внешними
   габаритами, материалом и входной апертурой, что и кандидат.

Первый контроль отвечает на прикладной вопрос «лучше ли обычного датчика»,
второй отделяет фокусировку от потерь и согласования самой конструкции.
Нельзя нормировать каждый вариант по собственной энергии на выходе и затем
называть результат системным усилением.

## 3. Каталог дефектов

Обязательный дешёвый gate:

- `none` — defect-free парный расчёт;
- `void_r2_focus` — круглая свободная полость радиуса `2 mm` на оси и глубине
  `60 mm`.

Расширенный каталог после прохождения gate:

- круглые полости радиуса `1` и `4 mm`;
- полость `r=2 mm` на глубинах `35` и `85 mm`;
- полость `r=2 mm` со смещением `10 mm` поперёк оси;
- тонкая эллиптическая трещина с полуосями `4.0 x 0.20 mm` под углами
  `0`, `15` и `30 deg`.

Круг и эллипс в 2D являются бесконечными out-of-plane дефектами. Сфера и
конечная penny-shaped crack остаются обязательной 3D-проверкой только для двух
лучших топологий.

## 4. Парное измерение

Для каждого дефекта сохраняются сигналы

```math
s_0(t) = \text{defect-free},\qquad
s_d(t) = \text{с дефектом},\qquad
\Delta s(t)=s_d(t)-s_0(t).
```

Итоговый режим — monostatic pulse-echo: одна и та же входная апертура излучает
и принимает. Поле на линии перед дефектом разрешено только как диагностический
observable и не является главным результатом.

## 5. Метрики и порядок приоритетов

### 5.1. Первичные NDT-метрики

- `echo_mf_gain_bare`: отношение пика согласованной фильтрации `Delta s` к
  `bare` при одинаковой энергии возбуждения;
- `echo_energy_gain_bare`: отношение энергии дефектного отклика в заранее
  фиксированном временном окне;
- `echo_to_ringing_db`: дефектное эхо относительно остаточного звона
  defect-free системы в том же окне;
- `dead_zone_depth_mm`: минимальная глубина, на которой эхо отделяется от
  возбуждения и звона по заранее фиксированному порогу;
- после добавления общего noise/clutter ensemble — `CNR` и POD, но до этого
  отношение амплитуд называется только `equal-noise SNR proxy`.

### 5.2. Ограничения на импульс и поле

```text
B_t <= 1.25
rho_pulse >= 0.90
postcursor/main <= 0.10
sidelobe/peak <= 0.35        (рабочий target, не скрытый hard gate)
```

Дополнительно сохраняются `S11`, переданная энергия, модовая конверсия,
FWHM, DOF и положение максимума. Амплитуда/энергия в фокусе остаётся
диагностикой механизма, но не ранжирует дефектоскопы сама по себе.

### 5.3. Изготовимость и робастность

Каждый кандидат обязан иметь конкретный маршрут изготовления, BOM-класс и
явно указанные минимальные элементы. Для первого металлического прототипа
рекомендуемый nominal gate — минимальная перемычка/прорез не меньше `0.8 mm`;
отклонение возможно только с названным процессом изготовления.

После дешёвого дефектного gate проверяются как минимум:

- изменение характерных размеров на `+-0.10 mm`;
- толщина контактного слоя и её вариация;
- поперечное смещение устройства `+-1 mm`;
- вариация скоростей материала образца `+-1%`.

## 6. Stage gates для каждого субагента

1. `G0 — manufacturable concept`: чертёж/параметризация, маршрут изготовления,
   диапазон эффективных свойств и ожидаемый механизм задержки.
2. `G1 — local transfer`: комплексный `S21`, `S11`, group delay и pulse metrics
   одной или нескольких характерных зон во всей `B_-20dB`.
3. `G2 — aperture without defect`: одинаковые `bare` и
   `straight_footprint`, фокус, FWHM, sidelobes, переданная энергия.
4. `G3 — paired defect`: `none` и `void_r2_focus`, defect subtraction и
   первичные NDT-метрики.
5. `G4 — robustness`: только после прохождения G3; расширенный каталог и
   manufacturing perturbations.

Субагент не обязан дорого считать G4, если G1 или G2 уже закрывает топологию.
Отрицательный результат с воспроизводимым no-go gate является полноценным
результатом.

## 7. Общий формат результата

Каждая ветка добавляет уникальные файлы без изменения чужих топологий:

```text
src/code/metamaterial/topology_<name>_*.jl
results/topology_benchmark/<name>/README.md
```

Raw meshes, JLD2, VTK и изображения остаются в `tmp/`. В README обязательны:

- точный commit и команды воспроизведения;
- геометрия, материалы и manufacturing assumptions;
- какие gates реально рассчитаны, а какие только оценены;
- таблица общих метрик с единицами;
- сравнение с обоими референсами;
- явные ограничения 2D/3D и harmonic/transient;
- verdict: `continue`, `conditional`, `stop`.

Минимальный CSV использует колонки из `ndt_benchmark.jl`; неизвестные метрики
записываются как `NaN`, а не заменяются несопоставимым proxy без маркировки.
