# O7: stationary four-state boundary — preregistered contract

> Frozen before the O7 numerical campaign on 15 August 2026.

## Question

Can one stationary, mirror-symmetric, three-port contact head generate four
usefully different measurement operators with only two global binary controls,
without element-wise phase control and without motion relative to the sample?

O7 is a reduced coupled-modal gate.  A positive result authorizes a coupled
plane-strain piezoelectric/full-wave model; it does not authorize fabrication or
a product POD claim.

## Architectures

All candidates use one fixed footprint, three reciprocal electronic ports and
12 transmit events (`3 ports x 4 states`).

1. `PZT-2bit`: a monolithic symmetric host with two independently switched
   mirror-pairs of bonded PZT patches.  Each pair is one global control zone;
   the two bits select four passive shunt states.  Resource ceiling: four PZT
   patches, two load switches, two passive RLC branches, no negative
   capacitance and no per-cell wiring.
2. `MECH-2bit`: the same modal host with two independently switched symmetric
   clamp/stiffness pairs.  It is a mechanism comparator, not a claim that the
   actuator is already designed.
3. `FREQ-K3Q1`: one fixed three-port state observed at the same seven frequency
   anchors.  It is explicitly a `Q=1` comparator; frequency samples are not
   relabelled as four physical states.
4. Frozen ideal `K3Q4`, one uniform A-scan and 17-channel FMC are controls.

## Reduced physical model

The host is represented by reflection-even and reflection-odd elastic modes.
For state `q=(b_A,b_B)` and angular-frequency ratio `f`, the port-to-aperture
map is

```math
W_q(f)=U\,[D(f)+\chi_A(b_A,f)K_A+\chi_B(b_B,f)K_B]^{-1}B.
```

`K_A` and `K_B` are generated by two spatially separated mirror-pairs and
therefore commute with reflection.  `D` contains host detuning and positive
damping.  The PZT branch uses positive-damping Lorentz/RLC feedback; the
mechanical branch uses positive stiffness and loss.  One common scale factor
per head enforces `max_{q,f} sigma_max(W_q(f)) <= 0.98`; state-wise
renormalization is forbidden.  The same complex `W_q(f)` is used on transmit
and receive, so the compressed response remains reciprocal.

This is a coupled-modal surrogate, not a piezoelectric FEM.  Dimensionless
feedback strengths are not manufacturing dimensions.

## Split and selection discipline

The O7 campaign uses a new base seed and new nuisance, signal and H0 splits.
The old O3 final-test split is not used for parameter selection.

1. Candidate parameters are screened against the already frozen ideal K3Q4
   subspaces and nominal operator metrics.
2. One PZT and one mechanical candidate are frozen using training clutter and
   signal-validation contexts only.
3. The final signal-test and H0-test splits are opened once for the frozen
   entrants and controls.

The defect grid, P/S Born library, C3 clutter powers, correlated frequency
noise, five-cycle pulse selection, amplitude grid and fixed-total-energy rule
remain those of the static O3 campaign.  There are 10,000 H0 validation and
10,000 H0 test draws, 24 signal-validation contexts and 60 signal-test
contexts.

## Positive controls and stop gates

Mandatory controls:

- reflection commutator error `<= 1e-10`;
- reciprocal compressed response error `<= 1e-10`;
- `max sigma(W) <= 1 + 1e-10` over every state and frequency;
- non-negative damping/loss parameters;
- four pairwise-distinct PZT and mechanical projectors;
- zero control coupling collapses exactly to one state;
- deterministic reconstruction from the saved seed and parameters.

An architecture passes the intrinsic detector gate only if all are true:

```text
Wilson upper 95% Pfa       <= 1.2%
Pd at fresh FMC alpha95    >= 0.90
Pdl at fresh FMC alpha95   >= 0.85
finite alpha90 on grid
```

In addition, a two-bit mechanism must beat its own `FREQ-K3Q1` comparator in
`alpha90` by at least 5%.  This prevents counting bandwidth alone as the
benefit of switching.

If neither two-bit branch passes, O7 stops: no geometry synthesis or FEM
optimization is authorized.  If one passes, the next step is a frozen
plane-strain coupled piezo/elastic (or contact-actuator) model with explicit
electrodes, loads, attachment and component tolerances.
