# Журнал развития вычислительной платформы метаматериалов

> Архив исследований до 9 августа 2026 года. Актуальные решения, ближайшие
> расчёты и критерии остановки вынесены в `research_plan.md`.

## 1. Долгосрочная цель

Создать воспроизводимую программу для прямого моделирования и обратного
проектирования конечных акустических метаматериалов, составленных из блоков
разной геометрии.

Расчётный конвейер должен иметь вид:

```text
параметры геометрии
    -> проверка ограничений
    -> Gmsh-сетка
    -> нативная Gridap-модель (отдельный процесс конвертации)
    -> Gridap FEM
    -> FFT-характеристика H(f) и вейвлетная time-frequency диагностика
    -> комплексные портовые характеристики S_i(f)
    -> библиотека блоков
    -> композиция блоков
    -> обратная задача
    -> проверка полной конструкции методом FEM
```

Нейросеть в этой архитектуре является быстрым приближением прямой задачи для
отдельного блока. Источником эталонных данных и окончательной проверкой остаётся
FEM-модель.

## 2. Ближайший предмет исследования

На первом этапе исследуется один слой из `N` элементов, расположенных поперёк
направления распространения. Плоская волна падает на слой только слева. Каждый
элемент приближённо считается независимым и описывается односторонней комплексной
передаточной характеристикой

```math
H_i(f) = |H_i(f)|\exp(i\phi_i(f)).
```

Взаимодействием соседних элементов внутри слоя на этом этапе пренебрегаем. Для
заданного входного поля локальный выход элемента определяется как

```math
U_{out,i}(f) = H_i(f) U_{in,i}(f).
```

После слоя поля элементов распространяются и интерферируют в общей области;
этот эффект сохраняется и используется для формирования фокуса. Не учитывается
только изменение локальной характеристики элемента из-за его соседей.

Геометрия элемента описывается семейством профилей, а не только амплитудой одной
синусоиды.

Начальные семейства:

1. существующий профиль (`LegacySinusoidalProfile`) для воспроизводимости уже
   рассчитанных данных;
2. периодический синусоидальный профиль;
3. экспоненциально деформированный синусоидальный профиль;
4. степенной профиль;
5. в дальнейшем - профиль Фурье и периодический B-spline.

Для корректного сравнения профилей фиксируются длина и ширина блока, число
периодов и минимальная ширина перемычки. Дополнительно сохраняются площадь,
длина границы, максимальный наклон и кривизна.

## 3. Требуемые физические характеристики

Вместо единственной пары «задержка - максимум выходной огибающей» необходимо
получать частотные характеристики:

- комплексное прохождение и отражение;
- энергетические коэффициенты `T(f)`, `R(f)` и потери `D(f)`;
- фазу `phi(f)` и групповую задержку `tau_g(f)`;
- конверсию продольных и поперечных мод;
- энергетический баланс;
- максимальные локальные напряжения;
- чувствительность к геометрическим и материальным параметрам.

Полная двухпортовая матрица блока определяется в модальном базисе портов:

```math
[b_L; b_R] = S_i(f) [a_L; a_R].
```

Отношение FFT выходного и заданного входного импульса само по себе не является
полной S-матрицей. Для вычисления `S_i(f)` нужны:

1. однородные входной и выходной порты;
2. собственные распространяющиеся и необходимые эванесцентные моды портов;
3. отдельное возбуждение каждой входной моды с обеих сторон;
4. комплексная проекция рассчитанного поля на портовые моды;
5. согласованная нормировка мод по мощности.

Полная S-матрица остаётся долгосрочным расширением. В текущем независимом
приближении слоя достаточно одностороннего `H_i(f)`, калиброванного относительно
прямого элемента одинаковой длины.

## 5. Первый вычислительный эксперимент

Сначала выполняется грубый пилот при одной несущей `220 кГц` и длительности
записи `120 мкс`. Его цель - проверить весь автоматический конвейер и формат
библиотеки до дорогого частотного перебора. В пилот входят:

- прямоугольный референс;
- синусоидальный профиль с амплитудой `2.5 мм`;
- экспоненциальные профили `sharpness = 1, 3`;
- степенные профили `power = 2, 4`;
- legacy-профиль с амплитудой `2.5 мм` для сопоставления со старым результатом.

Новые семейства имеют одинаковую минимальную ширину `2.0 мм`. Для
legacy-профиля сохраняется его фактическая минимальная ширина: из-за сдвига
верхнего и нижнего профилей она не обязана совпадать с новыми семействами.
FEM-задачи разных профилей запускаются параллельно в изолированных процессах;
Gmsh и Gridap по-прежнему не загружаются в один процесс.

После проверки пилота сравнить профили при одинаковой минимальной ширине:

- обычная синусоида;
- экспоненциальные профили с несколькими значениями `sharpness`;
- степенные профили с несколькими значениями `power`;
- существующая legacy-геометрия.

Следующий расчёт выполняется на несущих `160:20:280 кГц`: для каждой несущей
используются отдельный прямоугольный референс и окно `120 мкс`. Это даст первый
грубый набор кривых `H(f)`; после него сетка частот будет адаптивно уплотнена в
областях резкого изменения амплитуды и фазы. В рамках текущей скалярной модели
сравнивать комплексное прохождение и задержку. Отражение, энергетический баланс и
продольно-поперечную конверсию добавлять после модовой нормировки портов.

## 6. Правила обновления плана

- После изменения физической постановки сначала обновляется этот документ.
- Реализованный пункт отмечается только после проверки кодом или численным
  экспериментом.
- Формат сохранённых данных версионируется.
- Результаты surrogate-модели не считаются подтверждёнными без FEM-проверки.
- Изменения соглашений о знаках, фазах, нормировке мод и расположении
  референсных плоскостей фиксируются здесь до генерации нового датасета.

## 7. Известные технические ограничения

- Конфликт двух `libomp.dylib` на macOS устранён разделением процессов:
  `step1b_convert_models.jl` загружает GridapGmsh и сохраняет нативную
  Gridap-модель, а `step2_solver.jl` загружает только Gridap. Небезопасный обход
  `KMP_DUPLICATE_LIB_OK=TRUE` не используется.
- JSON-модель Gridap зависит от версии его внутреннего формата. После изменения
  версии Gridap её необходимо заново получить из исходного `.msh`; поэтому
  `.msh` остаётся источником истины, а `1_models/` не хранится в Git.
- Текущие усреднённые портовые величины достаточны для отладки одномодовой
  постановки, но не заменяют пространственную модальную проекцию и пока не
  являются полной S-матрицей.

## 8. Первый контрольный результат

Выполнены расчёты длительностью 120 мкс для прямоугольного референса `A = 0` и
legacy-профиля `A = 2.5` при центральной частоте 220 кГц. В последних 10%
записи пиковая амплитуда сырого выходного сигнала составляет менее 0.023% от
глобального максимума, поэтому временное окно достаточно длинное.

На ближайшем FFT-отсчёте 220.752 кГц получено:

- `|H_cal| = 0.08969`;
- `|H_cal|^2 = 0.00804` (амплитудный proxy, ещё не энергетическое пропускание);
- добавочная фазовая групповая задержка `12.49 мкс`;
- добавочная задержка кросс-корреляции огибающих `2.42 мкс`.

Сильное расхождение двух задержек подтверждает, что в зоне слабого пропускания
выходной импульс искажён и максимум корреляции не измеряет локальную групповую
задержку при 220 кГц.

Следующий этап - построить одностороннюю библиотеку `H(geometry, f)` для
синусоидального, экспоненциального и степенного семейств и исследовать доступный
диапазон амплитуд и фаз. Двустороннее возбуждение и полная S-матрица отложены до
момента, когда независимого приближения окажется недостаточно.

## 9. Пилотная библиотека на 220 кГц

Автоматический конвейер `run_pilot_sweep.jl` успешно выполнен для семи
геометрий. Четыре FEM-задачи запускались параллельно в отдельных Julia-процессах.
Повторный запуск пропускает готовые сетки, Gridap-модели и сигналы. Результаты
сохранены в `tmp/pilot_220khz/library_220khz.csv` и в машинно-читаемом JLD2.

Все значения ниже взяты на ближайшем FFT-отсчёте `220.752 кГц`:

|---|---:|---:|---:|---:|
| прямоугольный референс | 7.000 | 1.0000 | 0.000 | 0.000 |
| sinusoidal | 2.000 | 0.2200 | 2.082 | 5.488 |
| exponential, `sharpness=1` | 2.000 | 0.1999 | 1.620 | 5.003 |
| exponential, `sharpness=3` | 2.000 | 0.0958 | 0.815 | 3.711 |
| power, `power=2` | 2.000 | 0.1454 | 1.109 | 3.477 |

| legacy sinusoidal | 4.342 | 0.08969 | 1.377 | 12.486 |

`H(geometry, f)` на частотной сетке.

## 10. Грубые частотные кривые 160-280 кГц

Выполнены 49 расчётов: семь геометрий на семи несущих
`160:20:280 кГц`. Для каждой несущей рассчитан собственный прямоугольный
референс. Все целевые FFT-точки попали в допустимую область спектра входного
импульса. Таблица сохранена в
`tmp/pilot_220khz/library_frequency_sweep.csv` и JLD2-файле рядом с ней.

Основные наблюдения:

- синусоидальный профиль имеет наибольший модуль прохождения на всех точках от
  160 до 260 кГц;
- около 200-240 кГц у большинства профилей наблюдается область пониженного
  прохождения;
- при 280 кГц степенной профиль `power=4` достигает `|H| = 0.317`, больше
  остальных рассмотренных профилей;
- большие по модулю положительные и отрицательные локальные задержки возникают
  вблизи глубоких минимумов: например, exponential `sharpness=3` при 240 кГц
  имеет `|H| = 0.030` и `tau_g = -22.1 мкс`, а legacy-профиль там же имеет
  `|H| = 0.031` и `tau_g = 24.5 мкс`. Эти точки требуют более плотной частотной
  сетки и проверки сходимости;
- при 220 кГц доступный фазовый диапазон шести рассмотренных профилей составляет
  лишь около `1.3 рад`. Одной вариации формы при фиксированной амплитуде пока
  недостаточно для покрытия полного фазового диапазона, необходимого линзе.

Согласованность проверена в точке 220 кГц по импульсам с несущими 200, 220 и
240 кГц. Для профилей с `|H| > 0.09` разброс модуля составляет `0.4-3.4%`, а
расхождение фазы не превышает `0.091 рад`. У `power=4` относительный разброс
модуля достигает `10.5%` в глубоком минимуме `|H| ≈ 0.028`.

Уплотнение частотной сетки в области `210-250 кГц` с шагом `5 кГц` остаётся
полезным для отдельного исследования резонансных минимумов. Для основной задачи
линзы важнее сначала расширить геометрическую выборку по минимальному зазору:
именно она должна увеличить доступное фазовое покрытие при приемлемом `|H|`.

## 11. Вейвлетный анализ и ближайший этап

Вейвлетный анализ добавляется как диагностический слой над уже рассчитанными
временными сигналами. Основным представлением блока для библиотеки и обратной
задачи остаётся комплексная характеристика `H(f)`. CWT не заменяет её, а
проверяет временное происхождение резких фазовых изменений и больших задержек.

Первая реализация должна:

1. вычислять комплексное непрерывное вейвлет-преобразование Морле для входного
   сигнала, выхода прямоугольного референса и выхода образца;
2. сохранять комплексные коэффициенты либо достаточные производные величины:
   энергию `|W(f,t)|^2`, фазу, ridge времени прихода и маску cone of influence;
3. вычислять добавочную частотно-зависимую задержку образца относительно
   референса по временному центру энергии и корреляции вейвлетных огибающих;
4. оценивать локальное отношение `H_W(f,t) = W_sample/W_reference` только при
   достаточной энергии референса и сохранять отдельную маску доверия;
5. формировать JLD2-результат и скейлограммы, не запуская FEM повторно.

Первый контрольный набор использует существующие сигналы:

- sinusoidal `A=2.5` при 220 кГц как случай умеренного прохождения;
- power `p=4` при 220 кГц как глубокий минимум с отрицательной `tau_g`;
- exponential `sharpness=3` при 240 кГц как глубокий минимум с отрицательной
  `tau_g`;
- legacy `A=2.5` при 240 кГц как глубокий минимум с большой положительной
  `tau_g`;
- соответствующие прямоугольные референсы на каждой несущей.

Критерии готовности этапа:

- синтетический задержанный импульс восстанавливается с известной задержкой;
- сравнение референса с самим собой даёт нулевую добавочную задержку;
- результаты внутри cone of influence и при слабой энергии автоматически
  маскируются;
- в областях `|H| > 0.1` вейвлетная и FFT-задержки согласуются по знаку и
  масштабу либо различие объясняется несколькими приходами или ringing;
- для аномальных точек 220-240 кГц можно различить поздний резонансный хвост,
  многократные приходы и численно ненадёжное деление на малый сигнал.

## 12. Результат первого CWT-контроля

Комплексное CWT Морле первоначально было выполнено на сетке
`140:2:300 кГц`, а затем пересчитано на расширенной сетке
`50:5:1000 кГц` для четырёх контрольных сигналов. Нижняя граница выбрана из
условия, что вне cone of influence остаётся не менее половины записи
длительностью `120 мкс`; верхняя граница ограничена `1 МГц` и остаётся заметно
ниже частоты Найквиста `3.3--3.6 МГц`. На итоговых скейлограммах частота
отложена по горизонтальной оси, время — по вертикальной. Ridge автоматически
скрывается там, где относительная вейвлетная энергия ниже порога.

Ниже приведены значения на несущей. Столбец `|H|`
получен из FFT-калибровки, а CWT-задержки измеряют смещение временной огибающей
образца относительно прямоугольного референса.

| Профиль и несущая | `|H|` | `tau_g` FFT, мкс | CWT: центр энергии, мкс | CWT: корреляция, мкс | Доверие |
|---|---:|---:|---:|---:|---|
| sinusoidal, 220 кГц | 0.2200 | 5.488 | 3.515 | 3.333 | да |
| power `p=4`, 220 кГц | 0.0278 | -13.066 | 1.154 | 0.758 | нет: глубокий минимум |
| exponential `sharpness=3`, 240 кГц | 0.0304 | -22.094 | 0.281 | -0.972 | нет: глубокий минимум |
| legacy, 240 кГц | 0.0308 | 24.540 | 7.913 | 7.639 | нет: глубокий минимум |

У синусоидального профиля обе постановки дают положительную задержку одного
порядка. Их численное несовпадение нормально: `tau_g` измеряет наклон фазы, а
CWT — положение конечного импульсного пакета.

У профилей `power=4` и `exponential` большое отрицательное `tau_g` не
воспроизводится как ранний приход всего пакета. Это фазовый эффект вблизи
глубокого минимума прохождения, а не ускорение переноса сигнала. У legacy-профиля
виден действительно запаздывающий и искажённый пакет примерно на `8 мкс`, но
локальная производная фазы увеличивает оценку до `24.5 мкс`.

Вывод для основной задачи: точки с `|H| < 0.05` не следует использовать как
рабочие элементы линзы только ради большой задержки. Вейвлетная диагностика
остаётся готовым инструментом проверки подозрительных точек, но её дальнейшее
усложнение сейчас не требуется.

## 13. Пилот по числу периодов и длине

На частоте `220 кГц` выполнен отдельный пилот для синусоидального профиля с
амплитудой `2.5 мм` и минимальным зазором `2 мм`. Сравнивались:

- `N = 1, 2, 3, 4` при полной длине блока `17 мм`;
- длины `12, 17, 22 мм` при `N = 2`.

Каждый образец калибровался на прямоугольный блок той же длины. Поэтому из фазы
исключён тривиальный набег в дополнительном однородном материале, а результат
описывает добавочный эффект рельефа. Такая постановка соответствует рельефному
участку, дополненному прямым материалом до общей толщины слоя.

| `N` | Длина, мм | Шаг рельефа, мм | `|H|` | Фаза modulo `2pi`, рад | Класс |
|---:|---:|---:|---:|---:|---|
| 1 | 17 | 16.2 | 0.1171 | 6.027 | рабочий |
| 2 | 17 | 8.1 | 0.2200 | 2.082 | рабочий |
| 3 | 17 | 5.4 | 0.0080 | 5.974 | глубокий минимум |
| 4 | 17 | 4.05 | 0.00016 | 2.851 | глубокий минимум |
| 2 | 12 | 5.6 | 0.0835 | 2.512 | потерьный |
| 2 | 22 | 10.6 | 0.1050 | 0.879 | рабочий |

Число периодов является сильным, но дискретным регулятором. Переход от `N=1`
к `N=2` меняет фазу примерно на `2.34 рад` по кратчайшей дуге при допустимом
прохождении. Однако `N=3,4` на этой частоте практически закрывают канал, поэтому
их фазы не являются полезными точками библиотеки.

Длина даёт более плавное управление. При `N=2` изменение длины от `12` до
`22 мм` сдвигает фазу примерно на `1.63 рад`; две из трёх точек сохраняют
`|H| >= 0.1`, а короткий блок остаётся погранично потерьным. Поэтому длина
рельефного участка выглядит более перспективным непрерывным параметром, а для
следующего уплотнения достаточно оставить `N=1,2`.

Сравнение `N=3, L=17 мм` и `N=2, L=12 мм` особенно показательно: их шаги
рельефа близки (`5.4` и `5.6 мм`), но прохождение отличается примерно в десять
раз. Следовательно, ослабление определяется не только шагом, но и накоплением
эффекта нескольких вырезов.

Для рабочей точки `N=1` FFT дал добавочную групповую задержку `-7.17 мкс`.
CWT независимо подтвердил отрицательное смещение пакета: `-5.22 мкс` по центру
энергии и `-5.61 мкс` по корреляции огибающих, при корреляции `0.929`. Это
устойчивое опережение относительно прямоугольного референса вследствие
дисперсионного изменения формы пакета, а не отрицательное время распространения
и не нарушение причинности.

Результаты сохранены в `tmp/period_length_pilot_220khz`.

Пилот расширен до длин `12, 14.5, 17, 19.5, 22 мм`. Все новые случаи
рассчитаны тем же FEM-конвейером и откалиброваны на прямоугольные референсы

### Наблюдение о росте прохождения `N=1` при больших длинах

Для `N=1` модуль прохождения сначала уменьшается от `0.267` при `L=12 мм` до
`0.110` при `L=19.5 мм`, а затем возрастает до `0.132` при `L=22 мм`. Активные
длины этих крайних геометрий равны `11.2` и `21.2 мм`. При `c_p=2340 м/с` и
`f=220 кГц` продольная длина волны составляет около `10.6 мм`, поэтому крайние
точки находятся приблизительно возле одной и двух длин волн.

Рабочая гипотеза: ветвь проходит через интерференционный минимум, а подъём при
`22 мм` может быть началом следующего резонанса конструктивного прохождения,
аналогичного резонансу Фабри--Перо. Одновременно более длинный профиль имеет
меньшие наклоны стенок и может давать меньше обратного рассеяния. Это пока не
считается установленным механизмом: после основной геометрической библиотеки
следует построить подробные `H(f)` из уже имеющихся импульсов и проверить
систематический сдвиг резонанса с эффективной длиной.

## 15. Базовая конструкция первой печатной линзы

Для первого полного FEM и последующей 3D-печати выбирается монолитная пластина
со сквозными продольными прорезями, разделяющими семь волноводных элементов в
области метаповерхности. Это компромисс между двумя предельными вариантами:
отдельные стержни лучше соответствуют независимой модели, но требуют сложной
сборки и юстировки; сплошная пластина проще, но даёт сильную непосредственную
связь соседей.

Конструкция состоит из трёх последовательных областей:

1. сплошная входная площадка для равномерного возбуждения всех элементов;
2. область линзы из семи полос шириной `7 мм`, разделённых сквозными воздушными
   прорезями ориентировочной ширины `1.0--1.5 мм`;
3. сплошная выходная пластина, в которой прошедшие волны интерферируют и
   формируют фокус.

Все элементы имеют одинаковую полную длину области линзы `22 мм`. Более
короткий рельеф центрируется внутри неё и дополняется прямыми участками до общей
входной и выходной плоскости. Эта постановка согласуется с использованной
калибровкой на прямоугольный образец той же длины.

Деталь предполагается печатать плашмя: двумерный контур экструдируется на
постоянную толщину, а прорези проходят через всю толщину. Такая ориентация не
требует перекрытий над длинными каналами и подходит как для SLA/DLP, так и для
FDM при достаточной ширине прорезей. Точная ширина прорези, толщина экструзии и
допуски выбираются после фиксации принтера и материала.

При семи полосах реальная апертура больше `49 мм`, поскольку включает шесть
воздушных прорезей: около `55--58 мм`. Поэтому предварительное фокусное
расстояние следует увеличить с `50` примерно до `60 мм`, чтобы требуемый
фазовый размах оставался внутри доступных `3.56 рад`.

Перед изготовлением обязателен полный FEM всей печатной геометрии. Он должен
проверить связь через входную и выходную площадки, поведение волн у концов
прорезей, фокусное расстояние, боковые лепестки и чувствительность к ширине
технологических прорезей.

## 16. Первый прототип семиэлементной линзы

скалярная двумерная дифракция от семи конечных полос. Это ещё не FEM всей

## 17. Продолжение растущей однопериодной ветви

|---:|---:|---:|---:|

Физическая среда во всех текущих одиночных FEM-задачах — однородное упругое

элементов также интерпретируется как сплошная выходная пластина из того же
материала.

## 21. Контрастная оптимизация глубины фокуса

Для продольной локализации введена явная метрика глубины фокуса: длина
непрерывной области вокруг главного максимума, где интенсивность не ниже
половины максимальной, то есть `|u| >= |u_max|/sqrt(2)`. У исходной
девятиэлементной линзы эта глубина равна `51 мм` (`36.5--87.5 мм`).

Оптимизатор дополнен двумя режимами:

1. прежняя максимизация амплитуды в одной точке;
2. ограниченная контрастная оптимизация: потребовать амплитуду в цели не меньше
   заданной и среди допустимых комбинаций минимизировать среднюю интенсивность
   вне окна `60±10 мм` и в поперечных боковых лепестках.

При ограничении `|u(60 мм,0)|>=1` контрастный режим выбрал новую комбинацию и
получил:

- амплитуда в цели `1.006`;
- локальный максимум `1.032` при `x=53.5 мм`;
- глубина `-3 дБ` `47.5 мм` (`38--85.5 мм`).

Таким образом, изменение целевой функции сократило глубину только на `3.5 мм`
(`6.9%`) ценой уменьшения максимума с `1.115` до `1.032`. Более жёсткое окно
и разрешение снизить амплитуду в цели до `0.95` дали глубину около `44.5 мм`,
но максимум уже оказался ниже единицы.

Вывод: оптимизатор больше не является основной причиной длинного фокуса.
Ограничение задаётся эффективной числовой апертурой, девятью дискретными
полосами и доступными фазами. Для существенного сокращения до `20--30 мм`
потребуется увеличить апертуру до 11 элементов, уменьшить фокусное расстояние
или усилить крайние элементы с подходящей фазой. Контрастный прототип сохранён
в `tmp/lens_prototype_242khz_9elements_compact`.

## 22. Карта «фаза — максимальное прохождение»

Чтобы проверить идею «для каждой требуемой фазы выбрать элемент с наибольшим
прохождением», библиотека представлена как функция
`|H|_max(phi; delta_phi)`: для каждой целевой фазы ищется максимальный `|H|`
среди элементов, попавших в фазовый допуск `±delta_phi`. Это честнее, чем
требовать точного совпадения фаз: библиотека дискретна, а небольшой фазовый
промах линзовый оптимизатор может компенсировать соседними полосами.

На `242 кГц` при допуске `±15 градусов` обнаружены две принципиально разные
области:

- «дешёвые» фазы примерно `45--90` и `280--335 градусов`, где доступны
  элементы с `|H|` порядка `0.47--0.62`;
- «дорогая» область `160--240 градусов`: для `160--190` и около `235`
  градусов подходящих элементов вообще нет, а в диапазоне `195--230`
  градусов лучший `|H|` составляет только `0.025--0.060`.

Это объясняет слабый вклад крайних полос текущей линзы. Для крайней полосы
геометрическая фаза должна быть около `158 градусов`, то есть она попадает
ровно в непокрытую область. Выбранный оптимизатором элемент имеет неплохое
`|H|=0.374`, но его фаза отличается от требуемой примерно на `43 градуса`.
Следовательно, простая перестановка уже рассчитанных элементов не решит
проблему: библиотеке физически не хватает хорошо пропускающей геометрии с
фазой примерно `150--190 градусов`.

Следующий целевой FEM-поиск следует направить не на равномерное расширение
всей сетки параметров, а на заполнение этого фазового сектора. Практическая
цель первого поиска: получить в области `150--190 градусов` элементы с
`|H|>=0.4`, меняя длину, число периодов и при необходимости семейство профиля.
После этого нужно заново собрать девяти- и одиннадцатиэлементные линзы и
сравнить амплитуду в фокусе и глубину `-3 дБ`.

Воспроизводимый анализ находится в
`src/code/metamaterial/analyze_phase_efficiency.jl`. Таблицы, статические
графики и наборы Парето-кандидатов сохранены в `tmp/phase_efficiency`.

## 24. Связанные резонаторы: высокое прохождение и задержка

### 24.1. Физическая гипотеза

Следующий этап проверяет, можно ли получить большое прохождение и положительную
групповую задержку не за счёт поиска ещё одного одиночного профиля, а через
интерференцию двух связанных резонансных мод. Рабочий механизм является
упругим аналогом coupled-resonator-induced transparency, EIT и quasi-BIC:

1. яркая мода сильно связана с падающей продольной волной и сама по себе
   создаёт широкий провал прохождения;
2. тёмная мода слабо связана с портом, но связана с яркой модой коэффициентом
   `kappa` и запасает энергию;
3. на частоте прозрачности обратное излучение двух мод интерферирует
   деструктивно, поэтому отражение мало, а прямой и переизлучённый вперёд
   сигналы складываются конструктивно;
4. конечное время хранения энергии создаёт крутой наклон фазы и положительную
   групповую задержку.

Минимальная temporal coupled-mode модель записывается как

```math
\dot a_b = (i\omega_b-\gamma_b)a_b+i\kappa a_d
           +\sqrt{2\gamma_e}\,s_+,
```

```math
\dot a_d = (i\omega_d-\gamma_d)a_d+i\kappa a_b,
```

с типичной передаточной функцией

```math
t(\omega)=1-\frac{2\gamma_e}
{i(\omega-\omega_b)+\gamma_b+
 \kappa^2/[i(\omega-\omega_d)+\gamma_d]}.
```

Здесь `a_b`, `a_d` — амплитуды яркой и тёмной мод, `omega_b`, `omega_d` —
их собственные частоты, `gamma_e` — внешняя связь яркой моды с портом,
`gamma_b`, `gamma_d` — полные скорости затухания, `kappa` — межмодовая связь.
Формула используется как редуцированная модель и допускает изменение знаков и
нормировки при согласовании с принятой Fourier-конвенцией.

Ожидаемая ширина прозрачного окна имеет порядок

```math
\gamma_{tr} \sim \gamma_d + \kappa^2/\gamma_b.
```

Уменьшение `kappa` повышает задержку, но сужает рабочую полосу и увеличивает
чувствительность к потерям. Истинный BIC полностью развязан с портами и не
является рабочей точкой; практическая цель — quasi-BIC с конечной шириной,
достаточным прохождением и контролируемой задержкой.

Физический ориентир: D. Lee et al., *Elastic trapping by acoustoelastically
induced transparency*, Communications Physics 8, 87 (2025),
https://www.nature.com/articles/s42005-025-02001-8. Геометрия и размеры из этой
работы не копируются напрямую: сначала проверяется общий интерференционный
механизм в текущей чисто упругой двумерной постановке.

### 24.2. Минимальный чисто упругий прототип

Первый прототип не вводит воздушную акустическую область и совместим с текущим
векторным solver упругости. Вместо периодического профиля создаются два
локализованных симметричных сужения, разделённых прямым участком. Сужения играют
роль частично отражающих резонансных элементов, а участок между ними поддерживает
субрадиантную Fabry--Perot-подобную моду.

Новая параметризация должна развязать физически разные регуляторы:

- минимальные зазоры `g1`, `g2`;
- продольные ширины сужений `w1`, `w2`;
- расстояние между центрами `d`;
- длины прямых входного и выходного участков;
- малая контролируемая асимметрия `delta_g = g2 - g1` либо
  `delta_w = w2 - w1`.

Начальные ориентиры при `f0 = 242 кГц`, `lambda_p ~= 9.67 мм` и высоте полосы
`7 мм`:

- `g1 = 1.8--3.0 мм`;
- `w1, w2 = 1.5--3.5 мм`;
- `d = 3.5--8.0 мм`;
- `delta_g = 0, 0.1, 0.2, 0.3 мм` после нахождения симметричной рабочей точки.

Эти диапазоны являются стартовой сеткой, а не конструктивным оптимумом.
Проверка выполняется последовательно, чтобы не возвращаться к слепому полному
перебору:

1. Рассчитать одиночное сужение и подобрать `(g1, w1)`, создающее широкий
   резонансный провал около `242 кГц`. Это контроль яркой моды.
2. Добавить второе идентичное сужение и выполнить одномерный sweep только по
   `d`.
3. Найти спектр типа `провал -- пик -- провал`, локализацию энергии между
   сужениями и крутой фазовый переход на центральном пике.
4. Ввести малую асимметрию только после обнаружения симметричной связанной
   моды и подобрать конечную ширину quasi-BIC.
5. После этого локально уточнить `g1`, `g2`, `w1`, `w2`, не расширяя поиск на
   произвольные формы стенки.

Текущий профиль с `N=2` не считается достаточной проверкой: в нём ширина,
расстояние и глубина двух сужений связаны общей длиной и одной амплитудой, а
потому нельзя независимо управлять частотами мод и их связью.

### 24.3. Чисто упругий bright--dark элемент с локальными массами

Если два сужения дают только обычный Fabry--Perot-пик без полезной задержки и
полосы, следующим прототипом становится пара локальных упругих резонаторов:

- прямой несущий путь сохраняет нерезонансный канал прохождения;
- первый островок или локальная масса соединяется с несущим путём гибкой
  перемычкой и является ярким резонатором;
- второй островок связан преимущественно с первым и является тёмным
  резонатором;
- масса островков настраивает инерционный отклик, перемычки — жёсткость,
  соединение между островками — `kappa`, связь первого островка с полосой —
  внешнюю скорость утечки `gamma_e`.

Геометрия должна сохранять зеркальную симметрию по поперечной координате либо
использовать две симметричные пары резонаторов, чтобы не превращать прозрачность
в неконтролируемую конверсию продольной моды в поперечную. Такая топология
потребует расширить mesher внутренними отверстиями и несколькими граничными
циклами, но не требует добавления новой физики в упругий solver: поверхности
пустот остаются свободными от напряжений.

До scattering-расчёта следует выполнить eigenmode-анализ центральной области и
настроить две собственные моды в окрестность `242 кГц`. Для каждой моды
сохраняются симметрия, распределение кинетической и упругой энергии и ожидаемая
связь с продольной портовой модой.

### 24.4. Частотный FEM и обязательные наблюдаемые

Узкое прозрачное окно неудобно исследовать только импульсом длительностью
`120 мкс`: zero padding не увеличивает независимое частотное разрешение и не
восстанавливает долгий резонансный хвост. Для этого этапа приоритетен комплексный
гармонический solver с динамической матрицей

```math
[K - \omega^2 M + i\omega(\alpha M + \beta K)]u = f.
```

Начальный частотный sweep выполняется на `210:1:270 кГц`, а возле найденного
окна уплотняется до шага `0.1--0.25 кГц`. Transient-расчёт остаётся независимой
проверкой прохождения конечного импульса после выбора рабочей точки.

На каждой частоте необходимо сохранять не только калиброванный `H`, но и:

- модово-нормированные комплексные `t(f)` и `r(f)`;
- энергетические `T(f)`, `R(f)` и диссипацию `D(f)`;
- конверсию продольной моды в поперечные моды;
- фазу и `tau_g(f)`;
- интегральную кинетическую и упругую энергию в каждом резонаторе и в области
  между ними;
- интегральную мощность Rayleigh-диссипации;
- поля на левом провале, центральном пике и правом провале.

Сначала расчёт выполняется без материального демпфирования, затем с масштабами

```text
s = 0, 0.25, 0.5, 1,
(alpha, beta) -> s (alpha, beta).
```

Это разделяет отражение, модовую конверсию и внутренние потери. Полная модовая
S-матрица, ранее отложенная в долгосрочный этап, для этого исследования
становится ближайшей задачей: одного усреднённого `H_cal` недостаточно, чтобы
подтвердить прозрачность.

Спектр считается свидетельством связанной прозрачности только при одновременном
выполнении следующих признаков:

1. одиночный резонатор создаёт широкий провал;
2. пара создаёт два гибридных провала и центральный пик;
3. на пике отражение подавлено, а не только изменена средняя амплитуда порта;
4. энергия локализована в тёмной моде либо между резонаторами;
5. фазовая и временная задержки согласуются в рабочей полосе;
6. механизм сохраняется при ненулевых материальных потерях и малых
   технологических возмущениях.

### 24.5. Критерии первого успешного элемента

Предварительная цель чисто упругого прототипа на `242 кГц`:

- энергетическое прохождение `T >= 0.8`;
- отражение `R <= 0.1`;
- положительная добавочная групповая задержка `3--6 мкс`;
- полезная полоса прозрачности не уже `15--25 кГц` для первого
  нерекордного прототипа;
- высокая корреляция прошедшего импульса с задержанным референсом;
- отсутствие доминирующей конверсии в поперечную моду;
- сохранение различимого прозрачного пика как минимум при половине текущего
  демпфирования фотополимера.

Целью первого этапа не является максимальный `Q`: бесконечно узкий BIC не
пропускает полезный конечнополосный импульс и слишком чувствителен к потерям.
Оптимизируется компромисс `T -- tau_g -- bandwidth -- robustness`.

### 24.6. Точный вариант с воздушными полостями (отложено)

Точное воспроизведение acoustoelastically induced transparency из указанной
работы требует отдельных твёрдой и акустической областей. В твёрдом теле
решается динамическая упругость, в воздухе — уравнение для давления

```math
\rho_s \ddot u - \nabla\cdot\sigma(u)=0,
```

```math
K_a^{-1}\ddot p - \nabla\cdot(\rho_a^{-1}\nabla p)=0,
```

с непрерывностью нормального ускорения и условием `sigma n = -p n` на
интерфейсе. Для этого понадобятся смешанное пространство `(u, p)`, отдельные
физические группы Gmsh и интерфейсные интегралы.

Этот вариант не реализуется первым по следующим причинам:

- текущий solver содержит только упругую область, а пустоты трактуются как
  свободные поверхности;
- при `242 кГц` длина волны в воздухе около `1.42 мм`, поэтому резонансные
  размеры и перемычки могут стать субмиллиметровыми;
- в узких воздушных полостях понадобятся термовязкие потери;
- двумерная модель не воспроизводит объёмную моду закрытой 3D-полости без
  дополнительной проверки.

К fluid--solid модели переходить только если чисто упругая пара не достигает
требуемого компромисса либо экспериментальная конструкция принципиально должна
использовать закрытые воздушные объёмы.

### 24.7. Интеграция с фокусирующей линзой

Для стационарного фокуса требуется фаза на одной частоте, а для фокусировки
импульса — согласование времени прихода

```math
\tau_i + r_i/c_p \approx const.
```

При девяти полосах, `F = 60 мм` и крайнем центре `y = 32.8 мм` требуемый
диапазон дифференциальной задержки составляет только около `3.58 мкс`; при
одиннадцати полосах и `y = 41 мм` — около `5.41 мкс`. Поэтому большая общая
задержка не должна независимо максимизироваться для каждого элемента.

Предпочтительная архитектура разделяет две функции:

```math
t_i(\omega) = t_{common\ delay}(\omega)\,t_{focus,i}(\omega),
```

где одинаковая coupled-resonator-секция создаёт общую высокопроходящую
задержку, а отдельная высокопроходящая секция задаёт небольшой локальный
фазовый и дифференциально-задержочный профиль. Совмещённая односекционная
ячейка допускается позже, если она имеет достаточно независимых параметров для
одновременной настройки `T`, фазы и `tau_g`.

После получения одного подтверждённого прозрачного элемента выполняются:

1. построение малой библиотеки по физическим параметрам
   `(omega_b, omega_d, kappa, gamma_e)`, а не по произвольной форме;
2. подбор девяти- и одиннадцатиэлементных линз с ограничением на
   частотно-зависимое время прихода;
3. полный FEM всей линзы с взаимодействием полос;
4. сравнение амплитуды фокуса, энергетической эффективности, Strehl ratio,
   ширины и глубины фокуса с идеальной безотражательной апертурой.

### 24.8. Первый FEM-тест локальных связанных сужений

Реализован `CoupledConstrictionProfile`, в котором для каждого локального
сужения независимо задаются минимальный зазор `g_i`, продольная ширина `w_i`
и координата центра `x_i`. В отличие от прежнего периодического `N=2`, эти
параметры больше не связаны общей синусоидой.

Для разрешения узких спектральных особенностей добавлен комплексный
гармонический solver уравнения

```math
[K-omega^2 M+i omega (alpha M+beta K)+i omega C_port]u=f.
```

Пока сохраняется калиброванное отношение средних правопортовых смещений к
прямому референсу той же длины. Это `H_cal`, а не энергетически нормированный
S-параметр; поэтому результаты ниже являются спектральным скринингом, а не
окончательным доказательством энергетического прохождения.

#### Одиночное яркое сужение

На сетке `g=1.8, 2.4, 3.0 мм`, `w=1.5, 2.5, 3.5 мм` и
`210:2:270 кГц` наиболее выраженный широкий провал получен для
`g=1.8 мм`, `w=3.5 мм`:

- минимум `|H_cal|=0.031` при `232 кГц`;
- `|H_cal|=0.040` при `242 кГц`.

Эта геометрия использована как контрольная яркая мода.

#### Два одинаковых сужения

Для пары с `g_1=g_2=1.8 мм`, `w_1=w_2=3.5 мм` рассчитаны расстояния центров
`d=4--8 мм` с частотным шагом `1 кГц`.

При полном демпфировании наиболее заметный внутренний максимум возник для
`d=7 мм` при `226 кГц`, но остался слабым:

- `|H_cal|=0.041`;
- добавочная фазовая задержка около `4.7 мкс`;
- prominence относительно соседних минимумов только `0.0044`.

Большие значения производной фазы при `d=4 мм` отброшены как недостоверные:
в этой области `|H_cal|` падает до `10^-4`, и фаза становится неопределённой.

При нулевом материальном демпфировании связанная мода проявилась сильнее. Для
`d=6 мм` найден пик при `256 кГц`:

- `|H_cal|=0.058`;
- prominence `0.032`;
- фазовая задержка около `20.6 мкс`.

Это подтверждает наличие долгоживущего связанного резонанса, но не окна с
высоким прохождением.

#### Малая асимметрия зазоров

При полном демпфировании для `d=7 мм` проверены
`g_2=1.9, 2.0, 2.1 мм`. Лучший результат — `|H_cal|=0.044` и задержка
`5.4 мкс`; существенного открытия канала не произошло.

В lossless-расчёте около найденной моды `d=6 мм` с шагом `0.25 кГц` лучший
асимметричный вариант `g_2=2.0 мм` дал `|H_cal|=0.052` при `255.25 кГц` и
задержку `16.9 мкс`, то есть оказался хуже симметричной пары.

#### Вывод

Гипотеза подтверждена частично: независимое расстояние между сужениями
действительно создаёт долгоживущие связанные состояния и заметный фазовый
поворот. Однако два сильно перекрывающих прямой канал последовательных
сужения не реализовали constructive-transparency с большим прохождением, а
малая асимметрия не исправила это даже без материальных потерь.

Следующий тест не должен уплотнять `g_2` около уже исследованных точек. Есть
два физически осмысленных направления:

1. взять менее блокирующее одиночное сужение, сохранив прямой фоновый канал, и
   повторить ограниченный sweep `d`;
2. перейти к топологии с боковыми локальными массами из раздела 24.3, где
   прямое прохождение и тёмный резонатор геометрически разделены.

Код и результаты: `harmonic_solver.jl`,
`run_bright_constriction_search.jl`, `run_coupled_pair_search.jl`, каталоги
`tmp/bright_constriction_search`, `tmp/coupled_pair_search*`.

## 25. Боковые локальные массы и взаимодействие соседних полос

### 25.1. Геометрия следующего резонансного элемента

Следующий прототип сохраняет прямой продольный несущий путь и выносит
резонансные массы в стороны от него. Предпочтительна зеркально-симметричная по
`y` конструкция, чтобы продольное возбуждение не превращалось в основном в
изгиб или поперечную волну:

- центральная сплошная перемычка образует фоновый канал прохождения;
- верхняя и нижняя яркие массы соединяются с каналом шейками толщины `t_b`;
- верхняя и нижняя тёмные массы связаны преимущественно с яркими массами
  шейками `t_d` и слабо связаны с центральным каналом;
- размеры масс управляют эффективной инерцией, шейки — жёсткостью и связью;
- продольное смещение пар масс позволяет независимо настраивать межмодовую
  связь и фазу переизлучения.

Первый геометрический диапазон для печатного прототипа при общей высоте
`7 мм`:

```text
центральный канал h_c = 2.5--3.5 мм
шейки t_b, t_d       = 0.4--0.8 мм
длина массы l_m      = 1.5--4.0 мм
высота массы h_m     = 1.0--2.0 мм
продольный разнос    = 2.0--6.0 мм
общая длина элемента = 24--30 мм
```

Это стартовые ограничения для mesher, а не оптимальные параметры. Минимум
`0.4 мм` выбран как предварительно печатаемый масштаб; перед изготовлением он
должен быть согласован с фактическим принтером и ориентацией печати.

Для такой топологии текущего внешнего polygon-профиля недостаточно. Mesher
следует расширить операциями OCC union/cut: центральный канал, массы и шейки
объединяются в одну твёрдую область, а разделяющие щели становятся внутренними
свободными границами. Для вычисления локальных энергий яркие массы, тёмные
массы, шейки и центральный канал получают отдельные physical groups, хотя
материал у них одинаковый.

Порядок проверки:

1. построить и визуально проверить одну симметричную ячейку;
2. выполнить eigenmode-анализ без внешнего возбуждения и найти парные
   симметричную и антисимметричную моды около `242 кГц`;
3. выполнить lossless гармонический sweep и проверить локализацию энергии;
4. добавить демпфирование `s=0.25, 0.5, 1`;
5. только после подтверждения механизма оптимизировать `T`, задержку и полосу.

### 25.2. Когда допустимо считать полосы независимыми

Приближение независимых элементов было разумным для первого редуцированного
прототипа, но не является общим свойством будущей печатной линзы.

Если полосы являются отдельными твёрдыми деталями, разделены воздушными
щелями и не имеют общей рамки, то в текущей чисто упругой модели прямой
твёрдотельной связи между ними действительно нет. Остаются не включённые в
модель каналы: акустическая связь через воздух, общая система крепления и
взаимодействие уже вышедших волн.

Если линза печатается монолитно либо полосы соединены входной/выходной
площадкой, напряжения передаются через эти площадки. Тогда независимость не
гарантирована. При `242 кГц` характерные длины волн материала составляют
примерно `lambda_p=9.67 мм` и `lambda_s=4.83 мм`, а шаг текущих полос около
`8.2 мм`. Следовательно, геометрические масштабы не дают малого параметра,
который позволил бы заранее отбросить связь соседей. Для узких резонансных мод
чувствительность может быть ещё выше: слабая связь расщепляет частоты и
изменяет фазу сильнее, чем амплитуду вне резонанса.

### 25.3. Численный тест взаимодействия соседей

Проверка выполняется до полного FEM девятиэлементной линзы на минимальных
системах:

1. **Один элемент.** Сохранить комплексные портовые поля и резонансную частоту
   `f_0`.
2. **Димер одинаковых элементов.** Разместить две полосы с реальным зазором и
   теми же входной/выходной площадками, которые планируются в печатной детали.
   Возбудить сначала только одну полосу, затем обе синфазно.
3. **Димер разных элементов.** Повторить для двух геометрий, которые должны
   давать соседние фазы линзы.
4. **Три полосы.** Проверить центральный элемент между двумя соседями, чтобы
   отделить краевой эффект димера от объёмной связи массива.

Сохраняются:

- сдвиг и расщепление резонансных частот `Delta f`;
- изменение собственного прохождения `Delta t` и фазы `Delta phi`;
- cross-talk: мощность, появившаяся в выходном порту невозбуждённого соседа;
- распределение энергии в каждой массе и в общих площадках;
- отличие полного выходного поля от суммы изолированных элементов.

Предварительно модель независимых полос считается приемлемой в рабочей полосе,
если одновременно выполняются:

```text
|Delta |t|| / |t| < 5%
|Delta phi|       < 0.1 rad
|Delta f|         < 1 kHz
cross-talk power  < 1%  (-20 dB)
```

Пороги являются инженерным критерием первого прототипа и позже должны быть
связаны с допустимым падением Strehl ratio всей линзы.

### 25.4. Связь с оптимизатором линзы

Если взаимодействие мало, сохраняется нынешняя библиотека одиночных элементов.
Если оно заметно, необязательно сразу переходить к полному FEM при каждом шаге
оптимизации. Из расчётов димеров можно построить ближайше-соседнюю модель:

```math
b_i = t_i a_i + kappa_{i,i-1}a_{i-1}+kappa_{i,i+1}a_{i+1},
```

где коэффициенты `kappa` зависят от пары соседних геометрий и частоты. Такая
модель остаётся достаточно дешёвой для оптимизатора, а финальный кандидат всё
равно проверяется полным FEM всей линзы.

### 25.5. Первый FEM-прототип боковых масс

Построена симметричная ячейка длиной `30 мм` и высотой `7 мм` с входным и
выходным полноразмерными участками по `4 мм`, центральным каналом высотой
`3 мм`, парой ярких и парой тёмных масс. Яркие массы соединены с каналом
вертикальными шейками, тёмные — только с яркими тонкими продольными
перемычками. Прямой референс имеет те же площадки и центральный канал, но не
содержит боковых масс.

Lossless sweep `180:2:320 кГц` для ширин bright-шейки
`t_b=0.4, 0.6, 0.8 мм` обнаружил узкую Fano-подобную структуру около
`242 кГц`. Уточнение с шагом `0.25 кГц` и дополнительными
`t_b=0.5, 0.7 мм` показало:

- для `t_b=0.7 мм` максимум находится при `242 кГц`;
- `|H_cal|=1.012` на максимуме;
- фазовая задержка около `88 мкс`;
- непосредственно справа расположен узкий провал с `|H_cal|=0.547` при
  `242.75 кГц`.

Это пока называется Fano-подобным спектром, а не доказанной тёмной модой:
необходимо подтвердить противофазное движение и локализацию энергии по полям.
Кроме того, `|H_cal|>1` не является энергетическим усилением до модовой
нормировки портов.

Потери резко уменьшают добротность:

- при масштабе демпфирования `s=0.25` на `242 кГц` получено
  `|H_cal|=0.893`, а положительная задержка около `2 мкс` остаётся на левом
  плече возле `240 кГц`;
- при `s=1` на `242 кГц` получено `|H_cal|=0.933`, но полезная резонансная
  задержка практически исчезает.

Следовательно, топология сохраняет прямой канал и создаёт нужный
интерференционный профиль, но текущая мода слишком узкая. Оптимизировать нужно
не максимальный `Q`, а более сильную внешнюю связь и полосу при целевой
задержке `3--6 мкс` с ненулевым демпфированием.

### 25.6. FEM-проверка двух соседних ячеек

Две одинаковые ячейки размещены с шагом `8.2 мм` и соединены общими
полноразмерными входной и выходной площадками. Димер и одиночная ячейка
калибровались каждый на собственный прямой референс той же внешней геометрии.

В lossless-случае на `242 кГц`:

- `|H_cal|` одиночной ячейки: `1.012`;
- `|H_cal|` димера: `0.801`;
- относительное изменение амплитуды: `-20.8%`;
- изменение фазы: `0.137 рад`.

Коллективная резонансная линия заметно сдвинулась и деформировалась, поэтому
критерии независимости не выполнены.

При `s=0.25` ровно на `242 кГц` амплитудная ошибка уменьшилась до `0.4%`, но
фазовая осталась `0.098 рад`, а в соседней части полосы амплитудная ошибка
достигает `12.4%`.

При полном демпфировании `s=1` на `242 кГц` получено:

- изменение амплитуды `1.44%`;
- изменение фазы `0.0048 рад`;
- максимумы в диапазоне `238--248 кГц`: `2.35%` и `0.027 рад`.

Итог: для сильно затухающей широкой характеристики модель независимых
одинаковых соседей приемлема, но именно в режиме полезной высокодобротной
тёмной моды взаимодействие становится существенным. Поэтому дальнейшая
оптимизация боковых резонаторов должна проверять как минимум димер, а после
подбора разных фаз — димер из двух разных ячеек.

Реализация и результаты: `side_mass_mesher.jl`, `run_side_mass_pilot.jl`,
`run_side_mass_neighbor_test.jl`, `plot_side_mass_mesh.jl` и каталоги
`tmp/side_mass_*`.

## 26. Печатная материально-зависимая линза: цель и критерии

Этот раздел фиксирует концепцию следующего этапа до начала реализации. Она
должна быть отдельно проверена и при необходимости скорректирована. Ветка
синусоидальных профилей считается исследованной: найденные геометрии остаются
контрольной библиотекой, но дальнейшее уплотнение их параметрических sweep не
является основным направлением.

### 26.1. Минимальная постановка первой линзы

Чтобы не смешивать в одном прототипе слишком много задач, первая печатная
линза проектируется для:

- одного экспериментально откалиброванного материала;
- одной рабочей частоты `f0 = 242 кГц`;
- продольной падающей волны;
- одного стационарного фокуса;
- одной параметрической топологии элемента;
- семи или девяти полос в первом полном FEM.

Для стационарной линзы главными характеристиками элемента являются
`|H_i(f0)|` и `arg H_i(f0)`. Большая групповая задержка не является отдельной
целью первой версии: она важна только постольку, поскольку помогает получить
нужную фазу без потери прохождения. Согласование групповых задержек и
фокусировка импульсов остаются следующим, широкополосным этапом.

### 26.2. Предпочтительная печатная топология

Рабочая концепция — монолитная деталь постоянной толщины, печатаемая плашмя:

1. сплошная входная площадка;
2. параллельные полосы, разделённые сквозными технологическими прорезями;
3. в каждой полосе прямой центральный путь прохождения и зеркально-симметричные
   боковые резонансные области;
4. однородная выходная область того же материала, в которой формируется фокус.

Все прорези и полости на первом этапе должны быть сквозными, без закрытых
каналов и нависающих перекрытий. Конкретное исполнение боковых резонаторов
(внешние массы либо тот же механизм, сформированный внутренними прорезями)
пока не фиксируется. Сначала выбирается вариант, удовлетворяющий ограничениям
реального принтера.

Центральный путь должен сохранять фоновое прохождение, а боковые резонаторы —
добавлять переизлучённую составляющую с настраиваемой фазой. Это даёт больше
степеней свободы, чем одно сужение: размеры масс преимущественно задают
резонансные частоты, а шейки и межрезонаторные связи — силу связи с каналом и
ширину отклика. Амплитуда и фаза всё равно связаны пассивностью и потерями;
речь идёт только об их более гибкой совместной настройке.

### 26.3. Зависимость геометрии от материала и печати

В программу необходимо ввести две отдельные конфигурации:

- `MaterialConfig`: `rho`, `c_p`, `c_s` и модель потерь `eta(f)`;
- `ManufacturingConfig`: минимальная стенка, минимальная ширина прорези,
  минимальный радиус внутренних углов, толщина детали и ориентация печати.

Начальные геометрические размеры задаются не только в миллиметрах, а через
безразмерные отношения к длинам волн

```math
lambda_p = c_p/f_0, \qquad lambda_s = c_s/f_0.
```

Например, длина массы хранится как `l_m/lambda_p`, а абсолютный размер для
выбранного материала вычисляется генератором. Такое масштабирование даёт
разумную начальную геометрию при смене материала, но не заменяет FEM:
коэффициент Пуассона, потери, анизотропия печати и технологические допуски
требуют последующей настройки.

Перед проектированием физического образца свойства напечатанного материала
нужно откалибровать на прямых образцах нескольких длин. Паспортные значения
материала используются только как предварительные.

### 26.4. Нормировка усиления и энергетический смысл

Основная метрика линзы определяется как

```math
G = \frac{|u_{focus}|}{|u_0|},
```

где `u_0` — амплитуда падающей волны на входе при равномерном возбуждении
апертуры, а `u_focus` — амплитуда выбранной компоненты смещения в целевой
точке. Значение `G > 1` означает концентрацию энергии, собранной со всей
апертуры, а не активное усиление. При сравнении линз необходимо отдельно
указывать, фиксированы ли входная амплитуда на всей апертуре или полная
подводимая мощность.

Ближайшая целевая величина:

```math
G >= 2.
```

Она выглядит физически достижимой: в редуцированной модели идеальная линза той
же апертуры с `|H_i| = 1` давала `G ~= 2.33`, тогда как прототип из реальной
библиотеки давал около `1.08`. Поэтому первый резерв усиления находится в
прохождении и фазах элементов, особенно крайних полос. Значения `G = 3--5`
рассматриваются как цель следующего масштаба после проверки полной FEM-модели.
`G >> 2` нельзя обещать для нынешней пассивной однослойной апертуры без её
расширения, уменьшения фокусного расстояния либо перехода к фокусировке в двух
поперечных направлениях.

### 26.5. Глубина резкости и числовая апертура

Для ширины линзы `D` и фокусного расстояния `F` вводится оценка

```math
NA = \frac{D/2}{\sqrt{F^2 + (D/2)^2}}.
```

Диффракционные масштабы качественно ведут себя как

```math
w_{focus} \sim \frac{lambda}{NA}, \qquad
DOF \sim \frac{lambda}{NA^2}.
```

Следовательно, основной способ уменьшить глубину резкости — увеличить
апертуру `D`, уменьшить `F` или совместить оба изменения. Оптимизатор фаз сам
по себе не может компенсировать недостаточную числовую апертуру.

Для текущих ориентиров `D ~= 74 мм`, `F = 60 мм` получается `NA ~= 0.52`, что
согласуется с наблюдавшейся большой глубиной порядка `51 мм`. Переход к
`NA ~= 0.75` должен ориентировочно уменьшить её примерно вдвое, до
`24--25 мм`. Этого можно достичь либо при `F = 60 мм` и `D ~= 135 мм`, либо
при `D ~= 74 мм` и `F ~= 33 мм`, либо промежуточной комбинацией.

Рабочие критерии следующего прототипа:

```text
G >= 2
DOF_-3dB <= 25--30 мм
```

Одновременно должны контролироваться поперечная ширина фокуса, максимальный
боковой лепесток, отражение и чувствительность к производственным допускам.

### 26.6. Связь с фазированными решётками

После выходной плоскости линза описывается той же интерференционной суммой, что
и фазированная решётка. Отличие находится в реализации апертуры: активная
решётка независимо питает каждый излучатель, а пассивная линза должна получить
комплексные коэффициенты `H_i` из одной падающей волны. Поэтому готовые методы
формирования луча можно использовать для расчёта целевого апертурного поля, но
достижимость этого поля определяется прохождением, отражением, потерями и
взаимодействием печатных элементов.

Для высокой `NA` текущий шаг около `8.2 мм` (`~0.85 lambda_p`) может оказаться
слишком крупным. Следует отдельно сравнить его с шагом порядка
`lambda_p/2 ~= 4.8 мм`: более мелкая дискретизация должна уменьшить фазовое
алиасирование и паразитные лепестки, но усилит взаимодействие соседей и
повысит требования к печати.

### 26.7. Проверочные расчёты до оптимизации ячеек

Сначала выполняется идеальный апертурный тест без новых FEM-sweep геометрий:

1. текущая апертура `D ~= 74 мм` и короткий фокус `F ~= 35 мм`;
2. расширенная апертура `D = 110--140 мм` и `F = 60 мм`;
3. для обеих постановок сравнение шагов `8.2 мм` и `~4.8 мм`;
4. расчёт идеального поля при `|H_i| = 1` и точных фазах;
5. расчёт допустимого ухудшения при ограниченных `|H_i|`, фазовых ошибках и
   аподизации;
6. выбор наименьших `D`, `F` и числа полос, для которых одновременно возможны
   `G >= 2` и `DOF_-3dB <= 25--30 мм`.

Только после этого фиксируется требуемое распределение фаз и амплитуд по
апертуре, а новая материально-зависимая библиотека ячеек строится под конкретно
необходимые значения. Финальный кандидат обязательно проверяется полным FEM
монолитной линзы с соседним взаимодействием и ненулевыми потерями.

## 27. Абляция R0 / B / BD и первая анимация полей

Для проверки происхождения узкой линии реализованы три геометрии с одинаковыми
внешними площадками и центральным каналом:

- `R0` — прямой канал без боковых масс;
- `B` — канал и зеркальная пара bright-масс;
- `BD` — bright-массы и связанные с ними dark-массы.

Параметризация `SideMassConfig` разделена на размеры bright- и dark-масс.
Lossless-sweep выполнен в диапазоне `235--250 кГц` с шагом `0.25 кГц`.
Относительно `R0` получено:

```text
242.00 кГц: |H_B|  = 0.930
             |H_BD| = 1.012

242.75 кГц: |H_BD| = 0.540
```

Bright-only-геометрия не создала широкой резонансной подложки. Узкая
Fano-подобная структура появилась только после добавления dark-ветви.

Для `242.00` и `242.75 кГц` сохранены полные комплексные гармонические поля и
построены анимации
`Re[u(r) exp(-i omega t)]`. Деформация увеличена только для визуализации; цвет
показывает мгновенную продольную компоненту. Из узлового поля верхних масс
получено:

| Частота | bright RMS, мкм | dark RMS, мкм | dark/bright | Фаза dark-bright |
|---|---:|---:|---:|---:|
| `242.00 кГц` | `0.333` | `0.335` | `1.005` | `+1.3 градуса` |
| `242.75 кГц` | `0.783` | `0.814` | `1.040` | `-0.3 градуса` |

В обоих случаях массы движутся почти синфазно и с близкими амплитудами. На
провале движение bright-массы в полной ячейке примерно в `11` раз сильнее, чем
в случае `B`, но выходное `|H_cal|` мало. Это указывает на коллективный
резонанс и разрушительную интерференцию на выходе, но не на локализацию энергии
преимущественно в отдельной quasi-dark-моде.

Результат не закрывает bright--dark-ветку целиком: исходная точка имеет
одинаковые массы и ещё не проверяет независимую расстройку dark-частоты.
Следующая проверка — sweep `l_d`, затем `t_d`, eigenmode-классификация и
локальные интегралы энергии.

Воспроизводимые скрипты:

- `src/code/metamaterial/run_side_mass_ablation.jl`;
- `src/code/metamaterial/render_side_mass_ablation.jl`.

Данные, спектры, поля, кадры, GIF и MP4 находятся в
`tmp/side_mass_ablation`.

## 28. Консервативный модальный пилот B / BD

Реализован разреженный eigenmode-решатель для плоской линейной упругости.
Матрицы жёсткости и массы собираются в Gridap, а несколько собственных пар
около заданной частоты находятся shift-and-invert Arnoldi-методом без
формирования плотной обратной матрицы. Моды нормируются по матрице массы и
классифицируются по:

- чётности относительно средней линии `y`;
- доле продольного смещения;
- приближённой доле кинетической энергии в bright- и dark-массах;
- невязке обобщённой собственной задачи.

Для полной `B`-ячейки с зажатыми торцами наиболее локализованная чётная мода
получена при `217.476 кГц`, с долей в bright-массах `0.399`. При свободных
торцах наиболее локализованное чётное состояние находится при `209.753 кГц`,
с долей `0.440`. Следовательно, bright-only кластер расположен ниже целевых
`242 кГц` и заметно гибридизован с модами центрального канала; частота
отдельной bright-моды должна определяться в компонентном diabatic-базисе, а
не из закрытого спектра полной ячейки.

Для `BD` найдена локализованная чётная коллективная мода:

| Граница торцов | Частота, кГц | Bright fraction | Dark fraction | Сумма |
|---|---:|---:|---:|---:|
| зажатая | `242.523` | `0.203` | `0.213` | `0.416` |
| свободная | `242.675` | `0.204` | `0.214` | `0.418` |

Сдвиг частоты равен только `0.151 кГц`, а форма и локализация практически
сохраняются. Значит, состояние около `242.5 кГц` действительно локально в
боковых ветвях и не является простой стоячей волной между искусственными
границами. Рядом присутствует нечётный партнёр: `243.445 кГц` при зажатых и
`244.017 кГц` при свободных торцах. При симметричном продольном возбуждении
этот партнёр symmetry-protected и напрямую возбуждаться не должен.

Частота чётной локальной моды согласуется с Fano-пиком/провалом гармонической
абляции. При этом близкие bright/dark fractions подтверждают прежний вывод:
текущее состояние является коллективным, но ещё не доказанной quasi-dark-
модой. Следующий шаг — fixed-interface-компонентные моды, затем направляемые
портовые проекции и проверка связи этой моды с открытым scattering-откликом.

## 29. Fixed-interface-моды и управляемый Fano-резонанс

Для отделения локальной механики от искусственных стоячих волн лидов добавлены
две fixed-interface-задачи. В bright-компоненте зажимается основание шейки,
соединяющей массу с центральным каналом; в dark-компоненте зажимается левый
торец перемычки bright--dark. Все остальные поверхности свободны. При
`t_b = 0.7 мм`, `t_d = 0.5 мм` и длинах масс около `3 мм` обе компонентные
частоты лежат около `246 кГц`, то есть практически вырождены.

Однопараметрический sweep длины dark-массы показал причинную связь геометрии и
линии. На базовой сетке получено:

| `l_d`, мм | Полная чётная мода, кГц | Пик, кГц | Провал, кГц | Peak/dip |
|---:|---:|---:|---:|---:|
| 2.94 | 242.952 | 242.250 | 243.000 | 2.23 |
| 3.00 | 242.675 | 242.000 | 242.750 | 1.87 |
| 3.06 | 242.349 | 241.750 | 242.250 | 5.69 |

В гармонический решатель добавлен полный баланс средней мощности: работа
источника, поглощение на левом и правом импедансных портах и внутреннее
Rayleigh-рассеяние. Невязка баланса для рассчитанных точек имеет порядок
`10^-15`. Отношение выходной мощности к прямому образцу используется как
диагностика, но не называется абсолютным коэффициентом прохождения: при
заданной силе источник отдаёт геометриям различную мощность.

Сеточная проверка `l_d = 3.06 мм` дала частоты локальной чётной моды
`243.231`, `242.349`, `241.721` и `241.416 кГц` при последовательном
уточнении. Изменения уменьшаются, а характерный peak--dip сохраняется: на
сетке `h_min = 0.07 мм`, `h_max = 0.32 мм` контраст равен `5.40`. Ошибка
первой автоматической классификации на самой мелкой сетке обнаружила другую
локальную ветвь около `260.6 кГц`; выбор целевой моды ограничен окном
`230--250 кГц`.

После компенсации сеточного сдвига выбран финальный lossless-кандидат
`l_d = 2.80 мм` на сетке `h_min = 0.05 мм`, `h_max = 0.23 мм`:

```text
fixed bright component      245.974 кГц
fixed dark component        246.142 кГц
полная чётная мода          242.404 кГц
пик                         241.875 кГц, |H_cal| = 1.0134
провал                      242.375 кГц, |H_cal| = 0.0962
peak/dip                    10.53
Pout/Pout,R0 в провале      0.00939
```

Асимметричная амплитуда, резкий фазовый скачок, отсутствие этой линии в

изменении одной геометрической координаты подтверждают Fano-интерференцию
прямого и локального резонансного путей. При этом почти равные bright/dark-
доли полной моды не подтверждают quasi-dark/EIT-интерпретацию: текущая точка
классифицирована как коллективный одно-модовый Fano-резонанс.

| Масштаб Rayleigh-потерь | Peak/dip | Минимальный `|H_cal|` |

| 0.25 | 1.065 | 0.8786 |

## 30. Выбор идеальной широкополосной апертуры

После завершения Fano-пилота первая линза переведена в монохроматическую
phase-only-постановку. На `242 кГц` групповая задержка больше не является
целевой величиной: ячейка должна обеспечить нужные `|H(f0)|` и `arg H(f0)`.
Согласование `-d phi/d omega` потребуется только для будущей импульсной линзы.

Добавлен скалярный Huygens--Fresnel-пилот идеальной апертуры. Для каждой полосы
задаётся единичное прохождение и точная компенсирующая фаза, после чего напрямую
считаются поле, усиление в цели, осевой максимум, `DOF_-3dB` и поперечная
FWHM. Сравнены апертуры около `74, 110, 125, 140 мм`, фокусы `35/60 мм` и
шаги `8.2/4.8 мм`.

Выбран минимальный вариант, выполнивший `G_ideal >= 2.8` и
`DOF_-3dB <= 30 мм`:

| Параметр | Значение |
|---|---:|
| частота | `242 кГц` |
| число полос | `15` |
| шаг | `4.8 мм` |
| ширина полосы / паз | `4.2 / 0.6 мм` |
| фактическая апертура | `71.4 мм` |
| фокус | `35 мм` |
| `NA` | `0.714` |
| усиление в цели | `2.998` |
| осевой максимум | `3.031` при `x = 32.75 мм` |
| `DOF_-3dB` | `25.25 мм` |
| поперечная FWHM | `5.0 мм` |

При шаге `8.2 мм` девять полос той же апертуры и фокуса дают
`G_ideal = 2.646`. Поэтому выбранный шаг `4.8 мм ~= lambda_p/2` действительно
полезен для дискретизации и заполнения апертуры. При этом уменьшение шага не
доказывает независимость ячеек: соседнее взаимодействие будет проверяться
отдельной полной FEM.

Зеркальная линза требует восьми уникальных фаз от центра к краю:
`0`, `-12.2`, `-48.1`, `-106.0`, `176.8`, `83.1`, `-24.4`, `-143.3`
градуса. Эти значения становятся целями physical-cell continuation. Полное
равномерное покрытие `2pi` для первого прототипа не требуется.

## 31. Первый физический Huygens-пилот: две шунтирующие пары

Для полосы выбранной линзы построена монолитная ячейка длиной `24 мм` и
высотой `4.2 мм`. Она содержит прямой канал высотой `1.2 мм` и две зеркальные
пары боковых масс около `x = 8` и `16 мм`. Все массы подключены к каналу
напрямую; слабосвязанной dark-ветви нет. Геометрия имеет только сквозные
прорези, минимальную исследованную шейку `0.4 мм` и может печататься плашмя.

При Rayleigh-масштабе `s = 0.25` рассчитаны 20 вариантов:

- независимые длины передней и задней масс `2.4, 3.0, 3.6, 4.2 мм`;
- для равных масс дополнительные ширины шеек `0.4/0.8 мм`;
- частотная сетка `220--264 кГц` с шагом `2 кГц`;
- рабочая FEM-сетка около `8--9` тысяч узлов на ячейку.

Максимальное прохождение на `242 кГц` равно `|H_cal| = 0.990`. Несколько
кривых остаются выше `0.8` на десятках килогерц, поэтому требование
широкополосности само по себе достижимо. Однако высокопроходящие комплексные
коэффициенты лежат в одном секторе первого квадранта. Для точек с
`|H_cal| >= 0.8` фазовое покрытие равно только `0.646 рад`, или `37 градусов`.

Автоматическая сборка пятнадцатиполосной линзы смогла использовать фактически
только два разных элемента и дала:

```text

RMS фазовой ошибки         1.148 рад
минимальный |H| выбранных  0.930
```

То есть оптимизатор не является причиной неудачи: библиотека физически не
содержит требуемых фаз. Две пары масс создают две широкие локальные моды, но
обе являются шунтирующими нагрузками одного типа. Они не реализуют требуемые
для Huygens-согласования два противоположных по обратному переизлучению
отклика.

inertance. Это конкретная смена физического базиса, а не расширение текущего
декартова sweep.

## 33. Первый этап port-gate: моды однородной полосы

Перед новой геометрией реализована поперечная quadratic eigenvalue-задача для
свободной однородной полосы. Поле представлено как
`u(y) exp(gamma x) exp(i omega t)`, а линейные конечные элементы используются
только по координате `y`. Решатель возвращает распространяющиеся и затухающие
моды, их векторную чётность, кинематическое P/S-содержание, осевую долю
смещения, комплексные тяги и остаток собственной задачи. Распространяющиеся
моды нормированы на единичный поток мощности.

На `242 кГц` для полосы `4.2 мм` найдены три правонаправленные ветви:

```text
k =  632.288 1/м   antisymmetric   axial fraction = 0.872
k = 1152.099 1/м   symmetric       axial fraction = 0.258   <- input m=0
k = 1460.616 1/м   antisymmetric   axial fraction = 0.038
```

Таким образом, порт не является одномодовым. При идеально симметричной
геометрии равномерная продольная тяга имеет overlap только с симметричной
ветвью, но её фактический профиль на рабочей частоте уже существенно отличается
от равномерного. Выбор `m=0` сделан по симметрии фундаментальной S0-like-ветви
и проверен continuation от `10` до `242 кГц`. Минимальный overlap между
соседними точками с шагом `4 кГц` равен `0.9989`. Вдоль этой же ветви P-доля
падает примерно от `0.99` при `10 кГц` до `0.0085` при `242 кГц`, то есть
название quasi-longitudinal описывает происхождение и симметрию ветви, но не
локальный чисто продольный характер поля на рабочей частоте.

Сеточная последовательность для `m=0`:

```text
20 элементов: 1147.217 1/м
40 элементов: 1151.116 1/м
80 элементов: 1152.099 1/м
120 элементов: 1152.282 1/м
```

Изменение `80 -> 120` составляет около `0.016%`, остаток eigenproblem имеет
порядок `1e-12`. Также построена и конвертирована отдельная полная полоса
`reference_uniform` длиной `24 мм`; старый суженный `R0` в эту нормировку не
входит.

Для выбранной `m=0` получены фазовая скорость около `1320 м/с` и длина волны
`5.45 мм`. Это существенно меньше bulk-P-длины `c_p/f = 9.67 мм`. Первая
величина относится к свободной направляющей полосе и должна использоваться
внутри модели ячейки; вторая может оставаться длиной волны выходной среды
только если после линзы действительно находится сплошная bulk-пластина.
Переход от отдельных полос к общей выходной области поэтому становится
отдельной модовой задачей, а не автоматическим продолжением порта.

Затем реализована биортогональная Lorentz-reciprocity-проекция распределённых
смещений и тяг. На синтетической суперпозиции она восстанавливает комплексные
амплитуды встречных мод с ошибкой менее `1e-10`. На lossless-
`reference_uniform`, рассчитанном пока со старым равномерным источником и
локальными импедансами, получено:

```text
m0 справа на левом порту       91.7972 Вт/м
m0 слева на левом порту         1.6491 Вт/м
m0 справа на правом порту      91.6525 Вт/м
m0 слева на правом порту        1.3309 Вт/м
отношение полных net-потоков     1.0020
```

Нечётные моды имеют только малые численные амплитуды. Баланс net-потока с
невязкой около `0.2%` подтверждает проектор, но входящая справа мощность
составляет `1.45%` падающей `m=0`. Следовательно, локальная поглощающая граница
ещё создаёт обратную волну. Эти коэффициенты нельзя называть окончательной
`S`-матрицей до modal injection и modal DtN/PML.

## 34. Симметрийно-редуцированный modal port и абсолютный R0

После проверки проектора старые локальные поглощающие границы заменены на
модовые граничные условия. На каждом порту строится rank-one Robin-оператор,
который точно переводит профиль смещения выбранной `m=0` в соответствующую
тягу. Слева возбуждается нормированная правая `m=0`; справа задаётся только её
исходящее продолжение.

Это пока не полный multimode DtN. Редукция корректна для основной ветви
исследования, потому что геометрия и возбуждение симметричны относительно
`y = 0`: две остальные распространяющиеся моды на `242 кГц` нечётны и не
могут возбуждаться в точной симметричной задаче. Симметричные затухающие моды
не поглощаются точно, поэтому сечения портов нужно отнести достаточно далеко
от неоднородности. При нарушении симметрии, расчёте соседних элементов или
полной линзы понадобится полный DtN либо PML.

На lossless-образце `reference_uniform` длиной `24 мм` сначала обнаружилась
важная численная проблема: линейные объёмные конечные элементы давали малую
ошибку мощности, но заметную накопленную ошибку фазы. Поэтому все дальнейшие
фазочувствительные расчёты переведены на квадратичные объёмные элементы. Для
них абсолютная проверка дала

```text
R00 = 1.21e-7
T00 = 0.999914
C0  = 1.81e-9
net output / input = 0.999914
```

Проверка независимости от длины однородного порта:

```text
L, мм   R00        T00        incoming справа   ошибка фазы после de-embedding
12      4.32e-7    0.999984   1.39e-7           -0.00207 рад
24      1.56e-7    0.999875   1.08e-7           -0.00437 рад
36      2.46e-7    1.000061   1.29e-7           -0.00535 рад
```

Тем самым однородная калибровка проходит port-gate по мощности и фазе. При
этом проверка показала, что порядок объёмного FEM является частью физической
точности: линейная сетка может выглядеть хорошей по `T + R`, но быть
непригодной для проектирования фазовой линзы.

Затем тем же абсолютным проектором рассчитан `baseline_R0`: центральный
стержень высотой `1.2 мм` и длиной `18 мм` между полными полосами высотой
`4.2 мм`. Sweep длины прямых участков нужен из-за симметричных evanescent-мод;
для ближайшей из них характерная длина затухания около `4.65 мм`.

```text
lead, мм   T00       R00       C0         de-embedded phase

12         0.81038   0.18430   5.94e-8    0.8303 рад
```

участками `24 мм`:

```text

```

единицы не является абсолютным прохождением, однако R0 теряет на отражение
около `17%`, а не большую часть падающей мощности, как могло показаться из
старого source-work budget.

## 35. Fixed-interface продольная мода inline-массы M

Построен самостоятельный `M`-компонент основной mass--stiffness-топологии:
прямоугольная центральная масса между двумя одинаковыми продольными шейками.
Внешние вертикальные торцы шеек имеют `u = 0`, все остальные поверхности
свободны. Геометрия симметрична по `x` и `y`; минимальные длина и толщина шейки
ограничены `0.35 мм`. Это компонентная diabatic-задача: её частота нужна для
настройки и continuation, но не считается заранее точным полюсом открытой
ячейки.

Искомая мода выбирается не только по частоте. Для каждой собственной формы
сохраняются:

- чётность относительно `y`;
- доля продольного смещения;
- доля кинетической нормы в центральной массе;
- `rigid-x coherence` — отношение среднего `u_x` массы к его RMS;
- combined score этих величин.

Тем самым изгибная или поперечная мода, случайно попавшая в рабочее окно, не
может быть автоматически названа `M`-модой.

Первый однофакторный sweep для массы `2.0 x 3.0 мм` и шеек около
`0.5 x 0.6 мм` дал частоты только `112--159 кГц`. При этом зависимость имела
ожидаемые знаки: более толстая шейка повышает частоту, более длинная шейка и
более длинная масса её понижают. Комбинированное уменьшение длины массы и
укорочение шейки подняло верхнюю точку только до `174 кГц`, поэтому главным
дополнительным регулятором стала высота массы.

При фиксированных

```text
mass length  = 1.40 мм
neck length  = 0.35 мм
neck height  = 0.95 мм
```

continuation по высоте массы пересёк рабочую частоту:

```text
mass height, мм   f_M, кГц
2.1               291.57
2.3               259.59
2.4               244.69
2.5               230.68
2.6               217.55
2.7               205.31
```

Рабочим компонентным кандидатом принят `mass height = 2.4 мм`. Для него:

```text
f_M = 244.690 кГц
f_M - f0 = +2.690 кГц
mass fraction = 0.9955
rigid-x coherence = 0.8583
longitudinal fraction = 0.9663
parity_y = 1.0000
```

Таким образом, доказана отдельная чётная преимущественно продольная мода массы
немного выше `242 кГц`. Она не является идеально жёстким переносом
(`rigid-x < 1`), но однозначно отделена от соседних изгибных мод и пригодна как
начальная diabatic-ветвь.

Проверка квадратичного FEM тремя сетками:

```text

coarse      0.220          245.0286   +0.1960%
reference   0.150          244.6899   +0.0575%

```

Значит, настройка выше рабочей частоты не является сеточным артефактом;
уточнённая оценка равна примерно `244.55 кГц`. Следующий компонентный шаг —
построить нерезонансный прорезной `K`-блок и измерить его динамическую
комплаенсность. После этого `M` и две половины `K` можно объединять и проверять
сдвиг этой ветви в открытой задаче по абсолютным `S_00`.

## 36. Нерезонансный прорезной компонент K/2

Построена фиксированная печатаемая топология `K/2`: прямоугольный блок высотой
`4.2 мм` с тремя одинаковыми продольными сквозными прорезями. Прорези имеют
полукруглые окончания; между ними остаются четыре параллельных продольных
лигамента. Толщина лигамента является основным регулятором жёсткости, число
прорезей и связность не меняются.

Для компонента реализована FEM-оценка динамической жёсткости. Левое сечение
закреплено, правому задаётся единичное равномерное продольное смещение. Полная
обобщённая реакция вычисляется через lifting-поле, после чего

```math
K(\omega)=F_R(\omega)/U_R,
\qquad C(\omega)=1/K(\omega).
```

Одновременно решается fixed-interface eigenproblem с закреплением обоих
внешних сечений. Проверка показала, почему нужны обе задачи. Отсутствие
fixed-interface-собственной частоты около `242 кГц` само по себе не исключает
ноль динамической жёсткости и соответствующий полюс податливости при другом
типе граничного возбуждения.

Первый вариант длиной `4.2 мм` был отклонён: даже сплошной эталон имел
fixed-interface-моду около `242 кГц`. При длине `3.2 мм` собственные моды
сдвинулись, но блок оставался слишком длинным относительно направляемой волны,
и `K(242 кГц)` меняла знак. Длина `1.8 мм` убрала fixed-interface-полюса, но
для лигаментов `0.5--0.6 мм` нули `K(omega)` ещё попадали в рабочую полосу.

Финальная длина `K/2` принята равной `1.6 мм`, торцевые стенки — `0.35 мм`.
Она является минимальной для трёх скруглённых прорезей при текущих ограничениях
на радиус и печатную стенку. Lossless-sweep дал:

```text
t, мм   K(0)/Ksolid   C(242)/Csolid   variation K в 222--262 кГц   f_sym, кГц
0.40       0.452           7.876              316.34                 397.46
0.50       0.528           3.862                2.86                 388.19
0.60       0.606           2.540                1.95                 380.46
0.70       0.687           1.889                1.65                 373.86
0.75       0.728           1.675                1.57                 370.97
```

Здесь `variation K = max(Re K)/min(Re K)` в полосе. Первый gate требует
положительной `Re K` на всём интервале и variation не более `2`. Поэтому
`t=0.4` и `0.5 мм` отклонены как слишком близкие к динамическому полюсу.
Минимальным прошедшим кандидатом выбран

```text
length = 1.60 мм
height = 4.20 мм
end wall = 0.35 мм
ligament height = 0.60 мм
slot height = 0.60 мм
K(0)/Ksolid = 0.606
C(242)/Csolid = 2.540
nearest symmetric fixed-interface mode = 380.46 кГц.
```

Это не абсолютно частотно-независимая пружина: `K(omega)` монотонно меняется в
полосе. Но она остаётся конечной и положительной, не имеет полюса в
`222--262 кГц` и даёт примерно `40%` статического снижения жёсткости. Поэтому
компонент допустим как первая нерезонансная `K/2`, а варианты `0.7--0.75 мм`
сохраняются как более робастные точки continuation.

Сеточная проверка кандидата `t=0.60 мм`:

```text
mesh        K(242), ГН/м²   f_sym, кГц
coarse          3.11533       379.695
reference       3.13294       380.461
fine            3.14182       380.856
```

Отличие reference от fine равно примерно `0.283%` для `K(242)` и `0.104%`
для собственной частоты. Следующий шаг — собрать открытую симметричную ячейку
`K/2--M--K/2`, проследить сдвиг diabatic `M`-моды и впервые вычислить её
абсолютные `R_00`, `T_00` и фазу.

## 37. Первая открытая ячейка K/2--M--K/2

Отдельно настроенные компоненты из разделов 35--36 собраны без дополнительной
подгонки в одну x-симметричную открытую ячейку

```text
однородный порт -- K/2 -- M -- K/2 -- однородный порт.
```

Длина внутренней ячейки равна `5.3 мм`: два прорезных блока по `1.6 мм` и
массовый блок длиной `2.1 мм`. Выполнены четыре абсолютные модальные абляции с
одинаковыми внешними портами: `solid`, `K-only`, `M-only`, `combined`.
Возбуждается основная чётная quasi-longitudinal-мода; в диапазоне
`238--246 кГц` нежелательная распространяющаяся модовая конверсия численно
равна нулю в пределах точности проекции.

На целевой частоте `242 кГц` получено:

```text
variant    T00       R00       C0       de-embedded phase, rad
solid      1.0000    0.0000    0        -0.008
K-only     0.9641    0.0286    0        -0.106
M-only     0.3551    0.6444    0        -0.476
combined   0.0852    0.9134    0        -0.826
```

Следовательно, выбранный `K/2` сам по себе является хорошим широкополосным
проходным блоком, но массовый `M`-компонент уже создаёт сильное отражение.
Последовательная сборка не компенсирует его, а усиливает рассогласование:
проектирование `M` и `K` как независимых lumped-компонентов для этой короткой
ячейки оказалось недостаточным.

В полной ячейке `T00` растёт от `0.068` при `238 кГц` до `0.322` при
`246 кГц`; одновременно фаза меняется от `-0.75` до `-1.25 рад`. Это похоже
на начало коллективного окна K--M, сдвинутого выше компонентной частоты M, но
не является Huygens-точкой: даже в лучшей рассчитанной точке отражение остаётся
`R00 = 0.652`, а требуемая фазовая дуга с малым отражением отсутствует.

На частотах около `253 кГц` в однородном порту начинают распространяться ещё
две чётные ветви. Поэтому rank-one modal DtN не использовался выше `252 кГц`,
а уточнённый sweep ограничен `246 кГц`. Дополнительно проверена длина прямых
портов для полной ячейки:

```text

12         242      0.0852   0.9134   0.9986   -0.826
18         242      0.0858   0.9140   0.9998   -0.801
24         242      0.0886   0.9113   1.0000   -0.798
12         245      0.1727   0.8184   0.9911   -1.029
18         245      0.1915   0.8069   0.9983   -0.980
24         245      0.2055   0.7940   0.9995   -1.004
12         246      0.3223   0.6518   0.9741   -1.253
18         246      0.3972   0.5963   0.9936   -1.220

```

Главный отрицательный результат при `242 кГц` устойчив к длине портов. Правый
край диапазона чувствителен к медленно затухающему ближнему полю новой моды;
его количественные значения следует брать минимум с `24 мм` прямых участков
или после реализации полного multimode DtN. При этом даже уточнённая точка
`246 кГц` остаётся сильно отражающей и не меняет решение об отклонении текущей
сборки как готовой фазовой ячейки.

Анимация поля на `246 кГц` показывает большие противофазные деформации двух
прорезных половин и центрального массового блока, но одновременно сильную
стоячую волну во входном порту. Следующий геометрический шаг не должен быть
плотным sweep текущих размеров. Сначала нужен локальный physical-Jacobian
открытой ячейки по толщине/длине шеек M и комплаенсности K, чтобы выяснить,
существует ли направление, одновременно уменьшающее `R00` и управляющее
фазой. Если ранг или обусловленность неудовлетворительны, связность следует
изменить до поиска восьми фаз.

## 38. Контроль поглощающей и свободной правой границы

> Приведённые в этом разделе числа относятся к исходной синхронно
> суженной геометрии. Актуальный пересчёт для `_STG`-профиля записан в
> разделе 40.

Для исходной синусоидальной ячейки `A=2.5 мм`, `N=2` при `220 кГц` выполнено
прямое сравнение двух переходных FEM-задач на одной сетке:

- импедансная поглощающая правая граница `:absorbing`;
- свободная отражающая правая граница `:free_reflecting`.

Скейлограммы построены для средней нормальной скорости правого порта на общей
системе цветов `50--1000 кГц`. Скорость выбрана потому, что тяга на идеальном
свободном торце равна нулю. В отражающем случае максимум скорости оказался в
`1.365` раза выше, а интеграл `int |v_R(t)|^2 dt` — в `2.002` раза выше, чем
при поглощающей границе. Доля этого интеграла после `60 мкс` равна `0.0031%`
для поглощающего и `0.730%` для отражающего случая. CWT-карта отражающего торца
содержит длинную гребёнку поздних компонент, отсутствующую при поглощении.

Для семи стеночных топологий пилота построен общий график калиброванного
амплитудного прохождения `|H_cal(f)|` при поглощающей правой границе. Это
отношение к прямоугольному референсу; оно не интерпретируется как абсолютный
энергетический `S21`. Дополнительно сохранены реальные треугольные FEM-сетки
прямоугольной, sinusoidal, exponential `kappa=1,3`, power `p=2,4` и
legacy-топологий.

## 39. Переход от монохроматической фазы к импульсной фокусировке

После обсуждения с научным руководителем целевая постановка уточнена. На вход
подаётся конечнополосный импульс, а линза должна создать в твёрдом теле
пространственно и временно локализованный фокус с высоким gain и минимальным
размытием сигнала. Фотополимер остаётся материалом первого печатного
демонстратора; прикладная цель — присоединённый фокусирующий модуль для
алюминиевых деталей и задач неразрушающего контроля.

Поэтому восемь фаз на `242 кГц` больше не являются полной постановкой задачи.

входного импульса. Высокий резонансный `Q` отделён от качества фокуса: узкая
Fano-линия с ringing и потерей формы импульса не считается успешной.

журнале и не дублируются в актуальном плане.

## 40. Исправление фазировки верхней и нижней стенок

В пилотных `SinusoidalProfile`, `ExponentialProfile` и `PowerProfile`
обнаружена геометрическая ошибка: верхние и нижние максимумы
вырезов стояли друг напротив друга. При `H=7 мм`, `A=2.5 мм` это
сужало канал до `H-2A=2 мм` и создавало лишнее отражение.

Генератор изменён по образцу исходного `legacy`-профиля:

- верхняя стенка начинается на полпериода позже нижней;
- на общем участке верхняя граница есть вертикальный перенос нижней;
- толщина рабочего канала точно равна `H-A=4.5 мм` для всех трёх
  семейств;
- вход и выход сохраняют плавные полупериодные переходы.

Формат имён новых профилей имеет суффикс `_STG`, чтобы `skip_existing`
не переиспользовал старые сетки, модели и сигналы. Повторно построены
семь референсных сеток; все геометрические тесты и полный тестовый набор
проходят.

Численные результаты из разделов, построенных до этого исправления,
относятся к синхронно суженной геометрии. Их нельзя использовать как
количественные результаты новой `_STG`-геометрии; FEM-сигналы, `H_cal`,
задержки и CWT должны быть получены заново.

Первый повторный FEM-расчёт выполнен для пяти изменённых профилей при
несущей `220 кГц`. В ближайшей надёжной спектральной точке
`220.752 кГц` получено:

```text
rectangular       |H_cal| = 1.00000
sinusoidal STG    |H_cal| = 0.04863
exponential k=1   |H_cal| = 0.02739
exponential k=3   |H_cal| = 0.11546
power p=2         |H_cal| = 0.07545
power p=4         |H_cal| = 0.12960
legacy            |H_cal| = 0.08969
```

Удаление синхроного сужения не означает автоматического роста прохождения
на старой несущей: изменились длина периода, волновое сопротивление и
условия внутренней интерференции. На графике `_STG`-профилей главное
окно прохождения сместилось примерно к `140--160 кГц`. Следующий численный шаг —
не повторять плотный старый sweep, а сначала грубо перекартировать частоту
и длину периода для исправленной геометрии.

Контроль правой границы также пересчитан. Для свободной границы пиковая
скорость в `2.003` раза, а интеграл `int |v_R|^2 dt` в `4.658` раза больше,

использовать для оценки прохождения: он создаёт стоячую волну и длинный хвост.

## 42. Оптимистический идеальный impulse-aperture gate

Построен broadband true-time-delay baseline с одинаковой падающей амплитудой
на всей апертуре и явной нормировкой `G_peak` на однородную апертуру без
задержек. Propagator пока остаётся скалярным nondispersive bulk-P kernel;
поэтому результат является верхней границей, а не полноупругой валидацией.

```text

15 x 4.2 мм, D=71.4 мм   5.777 мкс       3.506              3.020
19 x 3.2 мм, D=71.6 мм   5.955 мкс       3.519              3.010
```

Для обеих апертур broadband `DOF_-3dB = 23.5 мм`, transverse FWHM `5.0 мм`.
FFT-проверка с `32768`, `65536` и `131072` точками изменила `G_peak` менее чем
на отображаемую шестую цифру.

`G_peak = 2.639` lossless и `2.229` при текущих Rayleigh-потерях; все временные

Модель потерь применяет Rayleigh-затухание только к добавочной задержке. Она не

## 43. Дисперсионный proxy геометрической задержки

Для полосы `3.2 мм` продолжена фундаментальная чётная ветвь во всём
`B_-20dB`. На несущей получено:

```text
phase velocity = 1748.96 м/с
group velocity = 1040.59 м/с.
```

Различие скоростей означает, что одна добавочная длина пути не может идеально
совместить carrier phase и group delay. Проверены два нерезонансных proxy:

1. `phase_matched_path`: длина выбирается по невёрнутой фазе на `f0`;
2. `group_matched_trim`: длина задаёт групповую задержку, а независимый
   частотно-слабый regulator исправляет carrier phase.

Для шести delay states при текущих Rayleigh-потерях:

```text
proxy                 max path   max trim   G_peak   B_t    rho     postcursor
phase_matched_path     10.42 мм     0       2.222   1.077  0.9715     0.061
group_matched_trim      6.20 мм   3.67 рад  2.664   0.967  0.9908     0.060
```

Простой path-only вариант требует общей дополнительной power-transmission не
ниже `0.810`, чтобы сохранить `G_peak >= 2`; это практически совпадает с
одиночным gate `Tbar_00 >= 0.8` и не оставляет инженерного запаса. Он падает до
`G_peak = 1.960` при `1.5x` текущего демпфирования. Ветка с phase-trim требует
только `T >= 0.564` по этому оптимистическому скалярному пересчёту и остаётся
на `G_peak = 2.276` даже при `2x` демпфировании.

Четыре path-only states при текущих потерях дали только `G_peak = 1.752`.
Шесть состояний являются первым устойчивым минимумом; восемь состояний не дали
монотонного улучшения из-за конкретного равномерного квантования.

Этот эксперимент проходит системный delay--bandwidth gate только на уровне
редуцированной прямой модели. В нём предполагаются идеальные изгибы и переходы,
нулевая модовая конверсия и отсутствие отражения. Следующий обязательный
эксперимент — абсолютный FEM для печатаемого path-delay элемента в полосе
`3.2 мм` с состояниями `0`, среднее и максимальное. Только он может подтвердить
физический topology gate.

## 45. Физический topology gate в одномодовом порте 3.2 мм

После положительных ideal/proxy-оценок проведены три последовательных
go/no-go эксперимента без запуска новой библиотеки геометрий. Во всех FEM
задачах использовались зеркально-симметричные ячейки, quadratic volume FEM,
power-normalized fundamental symmetric input и порт `3.2 мм`. Во всём
`B_-20dB` лишняя чётная портовая мода закрыта, нежелательная модовая конверсия
численно равна нулю, а lossless энергетический баланс замыкается с ошибкой не
хуже `2.2e-3` даже у верхнего края полосы.

### 45.1. Distributed slow-wave с продольными прорезями

Активная зона длиной `9.5 мм` содержит четыре одинаковые двухмиллиметровые
прорезные секции, разделённые цельными перемычками `0.5 мм`. Состояния:
`solid`, две центральные секции (`mid`) и все четыре (`max`). Геометрия
симметрична по `x` и `y`, минимальные ligament/end-wall не меньше `0.35 мм`.

Для ligament `0.45 мм` coarse lossless FEM дал:

```text
state   Tbar     Rbar    delay@242   minimum T
mid     0.558    0.442     0.18 мкс     0.005
max     0.451    0.549     8.10 мкс     ~0
```

Предельно слабый печатный вариант `ligament = 0.50 мм`, при котором радиус
прорези уже равен минимуму `0.20 мм`, не открыл transmission margin:

```text
state   Tbar     Rbar    delay@242   minimum T
mid     0.527    0.474    -0.38 мкс     0.159
max     0.551    0.449     3.53 мкс     0.023
```

Следовательно, эта связность даёт большую задержку только за счёт
чередующихся pass/stop-окон. Ослабление прорезей одновременно уменьшает delay,
но не приближает `Tbar/Rbar` к gate. Ветка закрыта до смены связности.

### 45.2. Tapered direct path с симметричным shunt trim

Вторая физическая топология сохраняет непрерывный осевой spine `1.6 мм`,
подключённый к полному порту косинусными переходами длиной `3 мм`. Симметричная
пара боковых масс подключена шейками `0.4 мм`; длины масс равны `2.4 мм`
(`mid`) и `4.0 мм` (`max`). Активная длина равна `12 мм`.

Грубая сетка выглядела положительно, поэтому выполнен fine-grid
`162:4:322 кГц`. Он обнаружил узкие стоп-полосы, пропущенные coarse-grid:
`mid` имеет `T = 0.0015` на `274 кГц`, `max` — минимум `T = 0.0535` около
`318 кГц`. Взвешенные и временные lossless-метрики:

```text
state   Tbar     Rbar   phase@242   delay@242    peak ratio   B_t    rho    post
mid     0.869    0.131   +0.841      -3.51 мкс      0.750    1.85  0.854  0.067
max     0.977    0.023   +0.968      -4.23 мкс      0.913    1.38  0.956  0.060
```

`max` проходит transmission, reflection, correlation и postcursor gates, но
не проходит `B_t <= 1.25`. Положительный фазовый trim сопровождается
аномальным отрицательным excess group delay и краевой резонансной дисперсией.

Краевой stop около `318 кГц` проверен удвоением каждого прямого lead с `12`
до `24 мм`. На `242 кГц` длинная модель дала `T = 0.99774`, `R = 0.00224`,
phase `0.9682 рад`; на `318 кГц` — `T = 0.05463`, `R = 0.94535`, phase
`-0.1501 рад`. Отличие от `12 мм` по `T` на краевой точке около `0.0011`,
поэтому stop не является артефактом медленно затухающей port-моды.

При текущих Rayleigh-потерях transfer калиброван отношением к solid strip той
же полной длины `36 мм`, чтобы численные leads и общий material path не
считались insertion loss ячейки. Для `max` получено:

```text
relative peak ratio = 1.105
B_t                 = 1.412
rho                  = 0.948
postcursor           = 0.053
```

Потери подавляют sharp resonance, но не исправляют broadening.

### 45.3. Оптимистический каскад измеренного trim

Чтобы не строить преждевременную четырёхсекционную библиотеку, измеренный
fine-grid `H_max(omega)` подставлен в шестисостоянийный group-matched path
proxy как идеальный каскад `H^n`, `n = 0..4`. Межсекционные отражения и coupling
искусственно исключены, то есть это верхняя граница. Единственным регулятором
был общий carrier-phase offset всей апертуры; после его оптимизации
используются все пять cascade counts и максимальный trim равен примерно
`3.8 рад`.

```text
case          G_peak    B_t    rho     postcursor   verdict
lossless       1.852   1.598  0.845      0.042      no-go
Rayleigh x1    2.009   2.196  0.829      0.048      no-go
```

В lossy-нормировке peak-gain едва пересекает `2`, но только вместе с
недопустимым растяжением и потерей сходства импульса. Поскольку даже
оптимистический независимый каскад не проходит gates, его полный FEM и новая
геометрическая библиотека запрещены.

Итоговый physical verdict: требуемый системный gain остаётся достижимым только
в идеальном delay/phase proxy; проверенные печатные 2D-связности не реализуют
его без stop-band либо сильной GDD. Следующий кандидат должен давать
широкополосный carrier trim с малой групповой производной, либо использовать
контролируемый третий размер. До такого результата разрешены только малые
диагностические эксперименты и homogeneous-aperture baseline.

## 46. Диагностический пилот прямого канала со сквозными отверстиями

Проверена идея периодических отверстий как возможного источника управляемой
фазы и задержки. Чтобы не смешивать эффект формы с количеством удалённого
материала, использованы три равноплощадные геометрии:

- круг `r=0.40 мм`;

Во всех случаях восемь отверстий расположены двумя выровненными симметричными
рядами внутри прямого канала высотой `3.2 мм`. Активная длина равна `12 мм`,
шаг отверстий — `2.4 мм`, центры рядов — `y=+-0.72 мм`, общая площадь пустот —
`4.021 мм^2`. Такая раскладка сохраняет прямую центральную перемычку и
запрещает нечётную модовую конверсию. Минимальные печатные перемычки равны

`162:20:322 кГц`. Однородный референс воспроизвёл `T00=1`, `R00=0` с ошибкой
энергобаланса порядка `10^-6`. В районе carrier `242 кГц` получено:

```text
геометрия              T00        R00
круг                  0.0104     0.9896
эллипс вдоль x        0.0005     0.9995
эллипс вдоль y        0.0071     0.9929
```

Следовательно, выбранная перфорация действует прежде всего как сильный
периодический отражающий фильтр. Она создаёт глубокую stop-band внутри
`B_-20dB`, а не широкополосную true-time-delay ячейку. Формальная производная
фазы внутри провала не интерпретируется как задержка: на итоговом графике
group delay скрыта, если хотя бы одна точка её разностного stencil имеет

На нижнем краю `162 кГц` компромисс ещё существует: для трёх форм

`242 кГц`. Форма отверстия не безразлична: она заметно сдвигает вторичные
окна прохождения, но ни одна из трёх равноплощадных форм не проходит текущий
широкополосный gate.

близости следующей modal cut-on и не используется для основного verdict.
Результат около `242 кГц` имеет корректный баланс и от этого ограничения не
зависит.

разрешённый эксперимент — небольшой `radius/pitch` detuning с меньшей долей
пустот или непериодической раскладкой, цель которого явно сдвинуть/ослабить
stop-band. Расчёты напряжений, CWT и импульсный transient для текущей
конфигурации не запускаются, поскольку она уже не прошла frequency-domain
transmission gate.

## 47.1. Мягкий экспоненциальный предел `κ=0.5`

Проверена гипотеза, что экспоненциальная стенка может быть одновременно
плавнее синусоидальной и лучше пропускать импульс. Для текущего семейства

```math
d(x)=A\frac{\exp(κs(x))-1}{\exp(κ)-1},
\qquad
s(x)=\frac{1-\cos(2πNx/L)}{2}
```

предел `κ->0` в точности равен синусоидальному профилю. У всех `κ` первая
производная на прямом стыке равна нулю. Положительный `κ` уменьшает вторую
производную непосредственно на стыке, но для достижения той же глубины на той
же длине увеличивает наклон и кривизну дальше по профилю.

Аналитические производные для `A=2.5 мм`, `N=2`, активной длины `12.96 мм`:

```text
κ      max|dy/dx|   |d2y/dx2| на стыке   max|d2y/dx2|
0.0      1.2120           1.1752             1.1752
0.5      1.2365           0.9058             1.4934
1.0      1.3021           0.6840             1.8592
3.0      1.7448           0.1847             3.7104
```

То есть `κ=0.5` действительно мягче синусоиды локально на входе: стыковая
кривизна меньше примерно на `23%`. Но максимальный наклон больше на `2%`, а
максимальная кривизна — на `27%`. Большие `κ` только сильнее переносят резкий
участок от стыка к вершине.

Вариант `κ=0.5` добавлен как отдельная topology во все существующие transient
расчёты. Working-band результаты:

```text
параметр                         sinusoidal       exp κ=0.5
|Hcal| при 140 кГц                 1.8816            1.8698
оценка -3 dB полосы, кГц       130.13--145.96    130.09--145.95
envelope shift при 140 кГц        -5.0 мкс          -5.0 мкс
пик выходной скорости              0.04476           0.04442
интеграл v^2 absorbing            1.278e-8          1.260e-8
reflecting/absorbing по v^2         3.192             3.372
```

Различие по `|Hcal|` меньше `1%`, по выходной энергии — около `1.4%` не в
пользу мягкой экспоненты. CWT для absorbing и free-reflecting границ визуально
совпадает с синусоидальным случаем; новой задержанной компоненты или более
чистого пакета не появилось.

Verdict: предположение о более мягкой локальной производной частично верно для
кривизны у стыка, но не даёт глобально более гладкой стенки и не улучшает
волновой отклик. Sweep по `κ<1` закрывается. Если требуется уменьшить и наклон,
и кривизну во всём профиле, эффективные регуляторы — большая активная длина и
меньшее число периодов, поскольку характерные производные масштабируются как
`1/L` и `1/L^2`.

## 48. Global-fold gate перед веткой Люнеберга

Проверена гипотеза, что требуемые `10.42 мм` дополнительного пробега можно
получить не локальной slow-wave ячейкой, а одним крупным складным путём,
использующим поперечное пространство всей линзы. Это отдельная проверка и не
противоречит packing bound раздела 44, где меандр был зажат внутри локальной
полосы шириной `3.2 мм`.

Из [работы Jeon и Oh по elastic coiling](https://doi.org/10.1103/PhysRevApplied.16.064016)
следует, что простой изгиб упругого пути сам по себе не эквивалентен
скалярному акустическому каналу: нужны специальные fluidlike connections и
isocurvature condition. Поэтому текущий
эксперимент поставлен как полноупругий transient-screening модовой конверсии,
а не как scalar path-length model.

### 48.1. Геометрия и референсы

Построены четыре независимые модели с прямыми портами шириной `3.2 мм` и
одинаковыми входными/выходными leads `12 мм`:

1. прямой путь с активной осевой длиной устройства `20 мм`;
2. прямой путь развёрнутой длины `30.42 мм`;
3. sharp mirror-like fold proxy из двух прямых сегментов;
4. rounded guided fold с half-cosine centerline и постоянной шириной по нормали.

Для sharp-варианта поперечный вынос вершины равен `11.4605 мм`. Для smooth
centerline амплитуда `10.7552 мм` найдена численно из условия arc length
`30.42 мм`. Минимальный внутренний радиус smooth-границы равен `0.284 мм`, что
выше принятого геометрического минимума `0.20 мм`, но имеет небольшой
производственный запас.

`sharp_fold` — только консервативный прокси цены резких отражающих соединений,
а не окончательная широкая пластина с отдельными диагональными воздушными
щелями. Rounded-вариант является буквальным непрерывным solid guide.

### 48.2. Пятицикловый transient

Все четыре сетки рассчитаны одним полноупругим Newmark transient с текущими
Rayleigh-потерями, Hann-импульсом `5 cycles`, `f0=242 кГц`, локальными
поглощающими условиями на прямых входном и выходном портах. Полезный observable
— средняя продольная скорость правого порта. Главная нормировка — прямой guide
той же развёрнутой длины, поэтому общий материальный пробег не приписывается
цене поворотов.

```text
variant              peak     normal E    B_t    rho     post    tangent E / normal E
straight device      1.436      1.975     0.947  0.987   0.087          ~0
straight equal path  1.000      1.000     1.000  1.000   0.085          ~0
sharp fold           0.284      0.070     0.698  0.836   0.042         1.362
rounded fold         0.565      0.240     0.709  0.926   0.092         1.297
```

Rounded fold заметно лучше sharp proxy и отдельно проходит формальные
`B_t/rho/postcursor` thresholds. Однако сжатие `B_t<1` здесь вызвано сильной
фильтрацией, а не идеальным сохранением импульса: primary amplitude gate
`peak fold/equal-path >= 0.8` не пройден. Полезный пик rounded-варианта равен
только `0.565`, энергия продольного выхода — `0.240` от референса.

У обоих folds усреднённая поперечная энергия на выходе больше продольной
примерно в `1.3` раза, тогда как у прямых референсов это отношение порядка
`10^-6`. Это прямо подтверждает исходный риск: широкий solid guide не
поворачивает продольную волну как скалярный акустический канал. Дополнительная
envelope-задержка rounded fold относительно equal-path равна `3.72 мкс`, но
она не считается полезной true-time delay при peak ratio `0.565`.

### 48.3. Verdict

Наивный planar global fold закрыт как непосредственный предшественник линзы:
увеличение радиуса уже улучшило peak `0.284 -> 0.565`, но не оставило
20-процентного transmission margin и не подавило P--S conversion. Плотный
radius sweep, CWT и axisymmetric full-lens расчёт для этой связности не
запускаются.

Результат не закрывает elastic coiling вообще. Возможное продолжение должно
сначала воспроизвести конкретную fluidlike/isocurvature connection из
литературы или перейти к геометрии, где поляризация кинематически защищена.
Только после локального peak gate `>=0.8` имеет смысл строить кольцевую
axisymmetric реализацию и полный multimode `S(omega)`.

## 54. Eight-source response matrix and amplitude precompensation stop

The next P5.1B package was executed on the frozen symmetric geometry. For each
of the eight nonnegative source groups, one independent right-hand side was
solved for both the monotonic lens and its matched straight reference. Source
group 1 represents the centre channel; groups 2--8 represent mirrored pairs.

Holding a reusable LU factorization of the `phase3/phase4` matrices left too
little macOS allocator headroom for a backsolve or post-solve boundary
integration. The response Jacobian was therefore evaluated on `phase2`

right-hand side in a fresh Julia process. This is a calibration mesh only;
the resulting single correction was independently accepted or rejected on

equal-drive solution with relative focus errors `2.72e-15` for the lens and
`1.37e-14` for the straight reference.

## 55. Broadband delay anchors and first monotonic path correction

The frozen v0 response-matrix experiment was extended from the `242 kHz`

The per-channel device transfer was defined from the diagonal preout
observable:

```text
H_i(f) = C_lens,ii(f) / C_straight,ii(f)

```

The zero-extra-path edge channel was subtracted as the common delay reference.
Seven channels form a consistent monotonic branch:

