# Виртуальный дефектоскоп с синусоидальной линзой

Автономный браузерный MVP, показывающий один узкий, но подтверждённый
численный эффект: при одинаковой приложенной нормальной тяге синусоидальная
алюминиевая линза повышает дефектный отклик на фиксированной приёмной линии
относительно согласованного прямого тракта.

## Запуск

Открыть `index.html` обычным браузером. Сеть, сервер и установка пакетов не
нужны.

На стенде можно:

- менять стандартное отклонение синтетического приёмного шума;
- включать и выключать дефект;
- получать новую реализацию одинакового шума для обоих трактов;
- сравнивать решение matched-filter детектора и модельную вероятность
  обнаружения при фиксированном `Pfa = 5%`.

## Что в данных настоящее

Профили взяты из парных 2D plane-strain FEM-расчётов `дефект − без дефекта`:

- алюминиевый surrogate;
- `242 kHz`;
- нормальная тяга `1 MPa`;
- цилиндрический 2D-дефект радиуса `2 mm` в номинальном фокусе;
- приёмная линия `x = 68 mm`;
- синусоидальная линза и её согласованный прямой контроль.

Авторитетный источник в основном дереве:

```text
results/sinusoidal_material_transfer_p6_242khz/defect/analysis/
```

Скопированные малые CSV лежат в `data/`, чтобы демо оставалось переносимым.

## Что добавлено только для демонстрации

Шум — независимый гауссовский шум одинаковой дисперсии. Matched filter знает
правильный чистый профиль. Аналитическая вероятность обнаружения рассчитана
для этого шумового предположения и фиксированного одностороннего порога
`Pfa = 5%`.

Поэтому MVP не является:

- измеренной вероятностью обнаружения;
- моделью электроники и структурного clutter;
- локализатором произвольного дефекта;
- временным A-scan;
- подтверждением изготовленного прибора.

## Проверка происхождения данных

Из каталога проекта:

```bash
julia --startup-file=no demo/sinusoidal_defectoscope/verify_demo.jl
```

Проверка пересчитывает RMS обоих профилей, отношение `1.44057` и
equal-noise SNR proxy `3.1707 dB`, а также проверяет, что ограничения явно
указаны в интерфейсе.

## Следующий физический уровень

Для настоящего виртуального дефектоскопа нужны новые парные расчёты по сетке
положений и размеров дефекта, широкополосные временные отклики и общий
noise/clutter ensemble. Они не подменяются интерполяцией этого единственного
центрального случая.
